### ✅ 2. Router 实现

创建了 `src/routers/archive.py`:

#### POST /api/archives/sync (核心接口)
**功能**: 档案同步 (归宗算法)

**逻辑**:
1. 接收前端传来的档案数组
2. 遍历每个档案:
   - 如果数据库中不存在 → INSERT
   - 如果数据库中已存在:
     - 对比 `local_created_at`
     - 只有当请求中的时间戳更晚时 → UPDATE
     - 否则 → 跳过
3. 返回云端所有最新档案列表

**关键代码**:
```python
for archive_data in request.archives:
    existing_archive = await db.execute(
        select(Archive).where(Archive.archive_id == archive_data.archive_id)
    )
    
    if existing_archive is None:
        # INSERT
        new_archive = Archive(...)
        db.add(new_archive)
    else:
        # 对比时间戳
        if archive_data.local_created_at > existing_archive.local_created_at:
            # UPDATE
            existing_archive.name = archive_data.name
            # ... 更新其他字段
```

#### GET /api/archives/list

#### DELETE /api/archives/{archive_id}

## 技术特点

### 1. 归宗算法
- **幂等性**: 多次同步相同数据不会产生副作用
- **冲突解决**: 自动选择最新的数据版本
- **离线支持**: 客户端可以离线修改，联网后同步

### 2. 异步操作
- 使用 `async/await` 语法
- `AsyncSession` 数据库会话
- 非阻塞 I/O

### 3. 数据验证
- Pydantic 自动验证请求参数
- 字段类型检查
- 取值范围限制

### 4. 错误处理
- 事务回滚
- HTTPException 异常
- 详细错误信息
