## ✨ 核心功能

### 1. 档案 CRUD 操作

#### fetchArchives() - 获取档案列表
```typescript
// 从云端获取用户的所有档案列表
await archiveStore.fetchArchives()
```

#### addArchive() - 添加档案
```typescript
// 添加新档案并同步到云端
const newArchive = await archiveStore.addArchive({
  name: '张三',
  gender: 1,
  birthDate: '1990-05-15',
  birthTime: '14:30',
  relation: '本人',
  isDefault: true
})
```

#### updateArchive() - 更新档案
```typescript
// 更新档案信息并同步到云端
await archiveStore.updateArchive(archiveId, {
  name: '李四',
  relation: '朋友'
})
```

#### deleteArchive() - 删除档案
```typescript
// 删除档案并同步到云端
await archiveStore.deleteArchive(archiveId)
```

### 2. 档案编辑页面

#### 新建模式
- 访问路径: `/pages/archive/add`
- 表单为空，等待用户输入
- 保存后设为当前档案

#### 编辑模式
- 访问路径: `/pages/archive/add?id=档案ID`
- 自动回显档案数据
- 支持删除操作

### 3. 云端同步

#### 自动同步
- 页面加载时自动同步
- 添加档案后自动同步
- 更新档案后自动同步

#### 手动同步
```typescript
// 手动触发云端同步
await archiveStore.syncWithCloud()
```

### 4. 本地持久化

#### 自动保存
- 档案列表自动保存到 localStorage
- 当前档案 ID 自动保存到 localStorage

#### 自动加载
- 页面加载时自动从 localStorage 加载数据

## 📊 技术实现

### 前端技术栈
- **框架**: Vue 3 + TypeScript
- **状态管理**: Pinia
- **UI 框架**: uni-app
- **样式**: SCSS + CSS Variables
- **图标**: Material Symbols

### 后端技术栈
- **框架**: FastAPI
- **数据库**: PostgreSQL
- **ORM**: SQLAlchemy 2.0
- **异步**: asyncpg

### 关键技术点
- ✅ Pinia 状态管理
- ✅ Vue 3 Composition API
- ✅ TypeScript 类型安全
- ✅ uni-app 跨平台
- ✅ RESTful API 设计
- ✅ 异步请求处理
- ✅ 本地持久化

## 📖 使用指南

### 快速启动

#### 1. 启动后端
```bash
cd bazi-admin
python main.py
```

#### 2. 启动前端
```bash
cd my-bazi-app
npm run dev:h5
```

#### 3. 访问页面
```
http://localhost:5173/#/pages/archive/add
```

### 代码示例

#### 新建档案
```typescript
import { useArchiveStore } from '@/store/useArchiveStore'

const archiveStore = useArchiveStore()

// 跳转到新建页面
uni.navigateTo({
  url: '/pages/archive/add'
})
```

#### 编辑档案
```typescript
// 跳转到编辑页面
uni.navigateTo({
  url: `/pages/archive/add?id=${archiveId}`
})
```

#### 获取档案列表
```typescript
// 获取所有档案
const archives = archiveStore.archives

// 获取当前档案
const currentArchive = archiveStore.currentArchive

// 获取默认档案
const defaultArchive = archiveStore.defaultArchive
```
