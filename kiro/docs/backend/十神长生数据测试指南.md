## 🔍 手动测试（使用 curl）

### 测试请求

```bash
curl -X POST "http://localhost:8000/api/fortune/calculate-by-data" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "测试用户",
    "gender": 1,
    "birth_year": 1990,
    "birth_month": 5,
    "birth_day": 15,
    "birth_hour": 14,
    "birth_minute": 30,
    "is_deep_analysis": false
  }'
```

### 检查响应

响应中的每个柱（year_pillar, month_pillar, day_pillar, hour_pillar）应该包含：

```json
{
  "gan": "庚",
  "zhi": "午",
  "nayin": "路旁土",
  "canggan": ["丁", "己"],
  "shishen": "比肩",              // ✓ 必须存在
  "changsheng": "沐浴",            // ✓ 必须存在
  "canggan_shishen": ["正官", "正印"]  // ✓ 必须存在
}
```

## 📊 数据验证要点

### 1. 十神（shishen）

- **年柱、月柱、时柱**：应该返回具体的十神名称（如：比肩、劫财、食神、伤官、偏财、正财、七杀、正官、偏印、正印）
- **日柱**：固定为 `"日主"`

### 2. 十二长生（changsheng）

应该返回以下之一：
- 长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养

### 3. 藏干十神（canggan_shishen）

- 应该是一个列表
- 列表长度应该与 `canggan` 长度一致
- 每个元素都是具体的十神名称

---

## ❌ 常见问题

### 问题 1：字段缺失或为空

**症状：**
```json
{
  "shishen": "",
  "changsheng": "",
  "canggan_shishen": []
}
```

**原因：**
- `bazi_engine.py` 没有正确调用 lunar-python 原生方法
- `fortune.py` 没有正确传递这些字段

**解决：**
检查代码是否使用了正确的方法名（注意时柱使用 `getTime...`）

### 问题 2：后端服务未启动

**症状：**
```
❌ 连接失败！请确保后端服务已启动
```

**解决：**
```bash
cd bazi-admin
python main.py
```

### 问题 3：依赖缺失

**症状：**
```
ModuleNotFoundError: No module named 'lunar_python'
```

**解决：**
```bash
pip install lunar-python
```
