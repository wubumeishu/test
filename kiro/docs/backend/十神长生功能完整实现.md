## 🔧 技术实现

### 1. 数据提取层（bazi_engine.py）

使用 lunar-python 的 `EightChar` 对象提供的原生方法：

#### 年柱
```python
shishen = bazi.getYearShiShenGan()           # 年干十神
changsheng = bazi.getYearDiShi()             # 年支长生
canggan_shishen = bazi.getYearShiShenZhi()   # 年支藏干十神
```

#### 月柱
```python
shishen = bazi.getMonthShiShenGan()          # 月干十神
changsheng = bazi.getMonthDiShi()            # 月支长生
canggan_shishen = bazi.getMonthShiShenZhi()  # 月支藏干十神
```

#### 日柱
```python
shishen = "日主"                              # 日干固定为日主
changsheng = bazi.getDayDiShi()              # 日支长生
canggan_shishen = bazi.getDayShiShenZhi()    # 日支藏干十神
```

#### 时柱（注意使用 Time 前缀）
```python
shishen = bazi.getTimeShiShenGan()           # 时干十神
changsheng = bazi.getTimeDiShi()             # 时支长生
canggan_shishen = bazi.getTimeShiShenZhi()   # 时支藏干十神
```

### 2. 数据模型层（bazi.py Schema）

```python
class PillarResponse(BaseModel):
    gan: str                                    # 天干
    zhi: str                                    # 地支
    nayin: str                                  # 纳音
    canggan: List[str]                          # 藏干
    shishen: Optional[str] = ""                 # 天干十神
    changsheng: Optional[str] = ""              # 地支长生
    canggan_shishen: Optional[List[str]] = []   # 藏干十神
```

### 3. API 接口层（fortune.py）

#### 响应数据构建
```python
year_pillar=PillarResponse(
    gan=result.year_pillar.gan,
    zhi=result.year_pillar.zhi,
    nayin=result.year_pillar.nayin,
    canggan=result.year_pillar.canggan,
    shishen=result.year_pillar.shishen,
    changsheng=result.year_pillar.changsheng,
    canggan_shishen=result.year_pillar.canggan_shishen,
)
```

## 📚 十神和长生说明

### 十神（Ten Gods）

十神是八字命理中的核心概念，表示天干之间的生克关系：

- **比肩**：同我（同性）
- **劫财**：同我（异性）
- **食神**：我生（同性）
- **伤官**：我生（异性）
- **偏财**：我克（同性）
- **正财**：我克（异性）
- **七杀**：克我（同性）
- **正官**：克我（异性）
- **偏印**：生我（同性）
- **正印**：生我（异性）

### 十二长生（Twelve Life Stages）

十二长生表示五行在十二地支中的状态：

1. **长生**：如人之初生
2. **沐浴**：如人之洗浴
3. **冠带**：如人之成年
4. **临官**：如人之壮年
5. **帝旺**：如人之鼎盛
6. **衰**：如人之衰老
7. **病**：如人之生病
8. **死**：如人之死亡
9. **墓**：如人之入墓
10. **绝**：如人之绝灭
11. **胎**：如人之受胎
12. **养**：如人之养育

## 🎯 关键要点

1. **lunar-python 原生方法**：直接使用库提供的方法，确保数据准确性
2. **时柱特殊命名**：lunar-python 中时柱方法使用 `Time` 前缀而非 `Hour`
3. **日柱特殊处理**：日干十神固定为"日主"，这是八字命理的标准规则
4. **藏干十神对应**：藏干十神列表与藏干列表一一对应，顺序一致
5. **向后兼容**：所有新增字段均为 Optional，不影响历史数据
