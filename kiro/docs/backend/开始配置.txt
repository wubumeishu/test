✅ 你已完成：
   - 安装 PostgreSQL
   - 启动 PostgreSQL 服务
   - 创建 zen_bazi 数据库

🎯 下一步（只需 1 分钟）：

┌──────────────────────────────────────────────────────────────┐
│  步骤 1：运行配置向导                                        │
└──────────────────────────────────────────────────────────────┘

打开命令行，运行：

    cd bazi-admin
    python setup_database.py

脚本会提示你输入 PostgreSQL 密码，输入后按回车即可。
（密码不会显示在屏幕上，这是安全特性）


┌──────────────────────────────────────────────────────────────┐
│  步骤 2：启动服务                                            │
└──────────────────────────────────────────────────────────────┘

配置完成后，运行：

    uvicorn main:app --host 127.0.0.1 --port 9000 --reload


┌──────────────────────────────────────────────────────────────┐
│  步骤 3：验证配置                                            │
└──────────────────────────────────────────────────────────────┘

访问以下地址：

    健康检查：http://127.0.0.1:9000/api/health
    API 文档：http://127.0.0.1:9000/docs
