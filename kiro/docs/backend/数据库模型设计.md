# 数据库模型设计

## 概述

本项目使用 SQLAlchemy 2.0 的现代语法 (`Mapped` 和 `mapped_column`) 定义数据库模型。

## 技术栈

- **ORM**: SQLAlchemy 2.0+
- **数据库**: PostgreSQL
- **异步驱动**: asyncpg
- **主键类型**: UUID (字符串格式)

## 模型列表

### 1. User (用户模型)

**表名**: `users`

**字段说明**:

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| user_id | UUID | PRIMARY KEY | 用户ID (UUID) |
| phone | String(20) | UNIQUE, NULLABLE | 手机号 |
| wechat_unionid | String(100) | UNIQUE, NULLABLE | 微信 UnionID |
| nickname | String(50) | NULLABLE | 昵称 |
| avatar_url | String(500) | NULLABLE | 头像 URL |
| created_at | DateTime | NOT NULL | 创建时间 (自动) |
| updated_at | DateTime | NOT NULL | 更新时间 (自动) |

**关联关系**:
- `archives`: 一对多关系，关联到 Archive 模型
- `records`: 一对多关系，关联到 Record 模型

**索引**:
- `phone` (唯一索引)
- `wechat_unionid` (唯一索引)

---

### 2. Archive (档案模型)

**表名**: `archives`

**字段说明**:

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| archive_id | UUID | PRIMARY KEY | 档案ID (UUID) |
| user_id | UUID | FOREIGN KEY, NOT NULL | 用户ID (外键) |
| name | String(50) | NOT NULL | 姓名 |
| gender | Integer | NOT NULL | 性别 (1=男, 0=女) |
| calendar_type | String(20) | NOT NULL | 历法类型 (solar/lunar) |
| birth_year | Integer | NOT NULL | 出生年份 |
| birth_month | Integer | NOT NULL | 出生月份 |
| birth_day | Integer | NOT NULL | 出生日期 |
| birth_hour | Integer | NOT NULL | 出生小时 |
| birth_minute | Integer | NOT NULL | 出生分钟 |
| tags | String(200) | NULLABLE | 标签 (逗号分隔) |
| is_default | Boolean | NOT NULL | 是否为默认档案 |
| local_created_at | BigInteger | NOT NULL | 本地创建时间戳 (毫秒) |
| cloud_uploaded_at | BigInteger | NULLABLE | 云端上传时间戳 (毫秒) |
| created_at | DateTime | NOT NULL | 创建时间 (自动) |
| updated_at | DateTime | NOT NULL | 更新时间 (自动) |

**关联关系**:
- `user`: 多对一关系，关联到 User 模型
- `records`: 一对多关系，关联到 Record 模型

**外键约束**:
- `user_id` → `users.user_id` (CASCADE DELETE)

**索引**:
- `user_id` (普通索引)

**核心同步字段说明**:
- `local_created_at`: 客户端本地创建时间戳 (毫秒)，用于离线同步
- `cloud_uploaded_at`: 云端上传时间戳 (毫秒)，用于判断是否已同步

---

### 3. Record (测算记录模型)

**表名**: `records`

**字段说明**:

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| record_id | UUID | PRIMARY KEY | 记录ID (UUID) |
| user_id | UUID | FOREIGN KEY, NOT NULL | 用户ID (外键) |
| archive_id | UUID | FOREIGN KEY, NOT NULL | 档案ID (外键) |
| bazi_str | String(100) | NOT NULL | 八字字符串 |
| five_elements_json | JSONB | NULLABLE | 五行分析 JSON 数据 |
| ai_report_markdown | Text | NULLABLE | AI 分析报告 (Markdown) |
| is_deep_analysis | Boolean | NOT NULL | 是否为深度分析 |
| created_at | DateTime | NOT NULL | 创建时间 (自动) |
| updated_at | DateTime | NOT NULL | 更新时间 (自动) |

**关联关系**:
- `user`: 多对一关系，关联到 User 模型
- `archive`: 多对一关系，关联到 Archive 模型

**外键约束**:
- `user_id` → `users.user_id` (CASCADE DELETE)
- `archive_id` → `archives.archive_id` (CASCADE DELETE)

**索引**:
- `user_id` (普通索引)
- `archive_id` (普通索引)

**JSONB 字段说明**:
- `five_elements_json`: 存储五行分析数据，支持 JSON 查询和索引

**示例 JSON 结构**:
```json
{
  "wood": 2,
  "fire": 1,
  "earth": 3,
  "metal": 1,
  "water": 1,
  "analysis": "五行较为平衡..."
}
```

## 级联删除规则

- 删除用户 → 自动删除该用户的所有档案和测算记录
- 删除档案 → 自动删除该档案的所有测算记录

## 使用示例

### 创建用户

```python
from src.models import User
from src.database import get_db

async def create_user(db: AsyncSession):
    user = User(
        phone="13800138000",
        nickname="张三",
        avatar_url="https://example.com/avatar.jpg"
    )
    db.add(user)
    await db.commit()
    await db.refresh(user)
    return user
```

### 创建档案

```python
from src.models import Archive
import time

async def create_archive(db: AsyncSession, user_id: str):
    archive = Archive(
        user_id=user_id,
        name="张三",
        gender=1,  # 男
        calendar_type="solar",
        birth_year=1990,
        birth_month=5,
        birth_day=15,
        birth_hour=14,
        birth_minute=30,
        tags="本人,重要",
        is_default=True,
        local_created_at=int(time.time() * 1000)
    )
    db.add(archive)
    await db.commit()
    await db.refresh(archive)
    return archive
```

### 创建测算记录

```python
from src.models import Record

async def create_record(db: AsyncSession, user_id: str, archive_id: str):
    record = Record(
        user_id=user_id,
        archive_id=archive_id,
        bazi_str="庚午 辛巳 丙寅 甲午",
        five_elements_json={
            "wood": 2,
            "fire": 3,
            "earth": 1,
            "metal": 2,
            "water": 0
        },
        ai_report_markdown="# 八字分析报告\n\n...",
        is_deep_analysis=True
    )
    db.add(record)
    await db.commit()
    await db.refresh(record)
    return record
```

### 查询用户及其档案

```python
from sqlalchemy import select
from sqlalchemy.orm import selectinload

async def get_user_with_archives(db: AsyncSession, user_id: str):
    stmt = select(User).where(User.user_id == user_id).options(
        selectinload(User.archives)
    )
    result = await db.execute(stmt)
    user = result.scalar_one_or_none()
    return user
```

## 注意事项

1. **UUID 格式**: 使用字符串格式存储 UUID，便于前端处理
2. **时间戳**: `local_created_at` 和 `cloud_uploaded_at` 使用毫秒级时间戳
3. **JSONB**: PostgreSQL 特有类型，支持高效的 JSON 查询
4. **级联删除**: 删除父记录时自动删除子记录
5. **索引优化**: 外键字段自动创建索引，提升查询性能

## 数据库迁移

未来如需修改表结构，建议使用 Alembic 进行数据库迁移:

```bash
# 安装 Alembic
pip install alembic

# 初始化
alembic init alembic

# 生成迁移脚本
alembic revision --autogenerate -m "描述"

# 执行迁移
alembic upgrade head
```
