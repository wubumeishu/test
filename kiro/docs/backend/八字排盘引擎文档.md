# 八字排盘引擎文档

## 概述

八字排盘引擎 (`bazi_engine.py`) 是基于 `lunar-python` 库实现的完整八字计算服务,提供高性能的排盘功能和详细的五行分析。

## 核心功能

### 1. 完整八字计算
- 四柱干支 (年月日时)
- 藏干信息
- 纳音五行
- 生肖信息

### 2. 五行分析
- 五行强度百分比 (金木水火土)
- 五行统计个数
- 日主五行属性

### 3. 数据验证
- 日期有效性检查
- 支持 1900-2100 年范围
- 闰年处理
- 边界情况处理

## API 文档

### calculate_full_bazi

**函数签名**:
```python
def calculate_full_bazi(
    year: int,
    month: int,
    day: int,
    hour: int,
    minute: int,
    gender: int = 1
) -> BaziResult
```

**参数**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| year | int | ✅ | 出生年份 (公历, 1900-2100) |
| month | int | ✅ | 出生月份 (公历, 1-12) |
| day | int | ✅ | 出生日期 (公历, 1-31) |
| hour | int | ✅ | 出生小时 (公历, 0-23) |
| minute | int | ✅ | 出生分钟 (公历, 0-59) |
| gender | int | ❌ | 性别 (1=男, 0=女, 默认1) |

**返回值**: `BaziResult`

**异常**:
- `ValueError`: 日期参数无效

**示例**:
```python
from src.services.bazi_engine import calculate_full_bazi

# 计算八字
result = calculate_full_bazi(1990, 5, 15, 14, 30, 1)

print(f"八字: {result.bazi_string}")
print(f"生肖: {result.shengxiao}")
print(f"日主: {result.day_master} ({result.day_master_wuxing})")
```

## 数据结构

### BaziResult

**字段说明**:

```python
@dataclass
class BaziResult:
    # 基础信息
    solar_date: str             # 公历日期 "YYYY-MM-DD HH:mm"
    lunar_date: str             # 农历日期 "一九九〇年四月廿一"
    gender: int                 # 性别 (1=男, 0=女)
    shengxiao: str              # 生肖 "马"
    
    # 四柱
    year_pillar: Pillar         # 年柱
    month_pillar: Pillar        # 月柱
    day_pillar: Pillar          # 日柱
    hour_pillar: Pillar         # 时柱
    
    # 八字字符串
    bazi_string: str            # "庚午 辛巳 庚辰 癸未"
    
    # 五行分析
    wuxing_strength: WuxingStrength  # 五行强度百分比
    wuxing_summary: Dict[str, int]   # 五行统计个数
    
    # 其他信息
    day_master: str             # 日主 "庚"
    day_master_wuxing: str      # 日主五行 "金"
```

### Pillar (四柱)

```python
@dataclass
class Pillar:
    gan: str                    # 天干 "庚"
    zhi: str                    # 地支 "午"
    nayin: str                  # 纳音 "路旁土"
    canggan: List[str]          # 藏干 ["丁", "己"]
```

### WuxingStrength (五行强度)

```python
@dataclass
class WuxingStrength:
    jin: float                  # 金 38.89%
    mu: float                   # 木 2.78%
    shui: float                 # 水 13.89%
    huo: float                  # 火 21.53%
    tu: float                   # 土 22.92%
```

## 五行计算算法

### 权重分配

1. **天干权重**: 30%
2. **地支权重**: 20%
3. **藏干权重**: 10% (平均分配)

### 计算公式

```
五行强度 = (天干得分 + 地支得分 + 藏干得分) / 总分 * 100%
```

### 示例

**八字**: 庚午 辛巳 庚辰 癸未

**天干**:
- 庚 (金) × 3 = 90分
- 辛 (金) × 1 = 30分
- 癸 (水) × 1 = 30分

**地支**:
- 午 (火) × 1 = 20分
- 巳 (火) × 1 = 20分
- 辰 (土) × 1 = 20分
- 未 (土) × 1 = 20分

**藏干**:
- 午藏: 丁(火), 己(土) → 各5分
- 巳藏: 丙(火), 戊(土), 庚(金) → 各3.33分
- 辰藏: 戊(土), 乙(木), 癸(水) → 各3.33分
- 未藏: 己(土), 丁(火), 乙(木) → 各3.33分

**总分**: 288分

**五行百分比**:
- 金: 38.89%
- 木: 2.78%
- 水: 13.89%
- 火: 21.53%
- 土: 22.92%
