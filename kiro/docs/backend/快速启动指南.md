# 快速启动指南

## 前置条件

✅ PostgreSQL 已安装并运行  
✅ Python 3.10+ 已安装  
✅ 已配置 `.env` 文件

## 启动步骤

### 1. 安装依赖

```bash
cd bazi-admin
pip install -r requirements.txt
```

### 2. 配置数据库

编辑 `.env` 文件:

```env
DATABASE_URL=postgresql+asyncpg://postgres:你的密码@localhost:5433/zen_bazi
```

## 数据库表说明

启动后会自动创建以下表:

1. **users** - 用户表
2. **archives** - 档案表
3. **records** - 测算记录表

详细字段说明请查看: [数据库模型设计.md](./数据库模型设计.md)

## 常见问题

### Q1: 连接数据库失败

**检查**:
- PostgreSQL 服务是否运行
- 端口是否正确 (默认 5433)
- 密码是否正确
- 数据库 `zen_bazi` 是否存在

### Q2: 表已存在错误

**解决**:
```sql
-- 删除所有表 (谨慎操作!)
DROP TABLE IF EXISTS records CASCADE;
DROP TABLE IF EXISTS archives CASCADE;
DROP TABLE IF EXISTS users CASCADE;
```

然后重新启动服务。

### Q3: 导入模块失败

**检查**:
- 是否在 `bazi-admin` 目录下运行
- 是否安装了所有依赖
- Python 版本是否 >= 3.10
