## 📅 更新时间
2026-04-29

## ✅ 更新内容

为了支持前端更专业的八字排盘 UI，扩充了后端返回的数据结构，新增了十神、十二长生和藏干十神字段。

### 一、Schema 层修改

**文件**：`bazi-admin/src/schemas/bazi.py`

#### 修改 PillarResponse 模型

```python
class PillarResponse(BaseModel):
    """四柱响应 Schema"""
    gan: str = Field(..., description="天干")
    zhi: str = Field(..., description="地支")
    nayin: str = Field(..., description="纳音")
    canggan: List[str] = Field(..., description="藏干")
    
    # 新增字段（可选，兼容历史数据）
    shishen: Optional[str] = Field(default="", description="天干对应的十神（如：偏印、伤官、比肩）")
    changsheng: Optional[str] = Field(default="", description="地支对应的十二长生/地势（如：沐浴、建禄、帝旺）")
    canggan_shishen: Optional[List[str]] = Field(default_factory=list, description="藏干分别对应的十神列表")
```

**说明**：
- 所有新增字段都是 `Optional`，并提供默认值
- 确保与历史数据兼容，不会因为缺少字段而报错

#### 2. 修改 Pillar 数据类

```python
@dataclass
class Pillar:
    """四柱（年月日时）"""
    gan: str        # 天干
    zhi: str        # 地支
    nayin: str      # 纳音
    canggan: List[str]  # 藏干
    shishen: str = ""  # 十神
    changsheng: str = ""  # 十二长生
    canggan_shishen: List[str] = None  # 藏干十神
    
    def __post_init__(self):
        """初始化后处理"""
        if self.canggan_shishen is None:
            self.canggan_shishen = []
```

#### 3. 新增计算函数

##### get_shishen() - 计算十神
```python
def get_shishen(day_gan: str, target_gan: str) -> str:
    """
    计算十神
    
    算法：
    1. 获取日主和目标天干的五行属性
    2. 根据五行关系确定基础十神
    3. 根据阴阳属性确定具体十神（同性为偏，异性为正）
    
    Args:
        day_gan: 日主天干
        target_gan: 目标天干
        
    Returns:
        十神名称
    """
```

**十神关系**：
- **比肩/劫财**：同我（同五行）
- **食神/伤官**：我生（日主生目标）
- **偏财/正财**：我克（日主克目标）
- **七杀/正官**：克我（目标克日主）
- **偏印/正印**：生我（目标生日主）

**阴阳规则**：
- 同性（阳对阳、阴对阴）→ 偏（比肩、食神、偏财、七杀、偏印）
- 异性（阳对阴、阴对阳）→ 正（劫财、伤官、正财、正官、正印）

##### get_changsheng() - 计算十二长生

```python
        zhi: 地支

    """
```

**十二长生**：
- 长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养

#### 4. 修改 calculate_full_bazi() 函数

在创建每个 Pillar 对象时，自动计算十神、十二长生和藏干十神：

```python
# 年柱
year_gan = bazi.getYearGan()
year_zhi = bazi.getYearZhi()
year_canggan = DIZHI_CANGGAN.get(year_zhi, [])
year_pillar = Pillar(
    gan=year_gan,
    zhi=year_zhi,
    nayin=get_nayin(year_gan, year_zhi),
    canggan=year_canggan,
    shishen=get_shishen(day_gan, year_gan),  # 新增
    changsheng=get_changsheng(day_gan, year_zhi),  # 新增
    canggan_shishen=[get_shishen(day_gan, cg) for cg in year_canggan]  # 新增
)
```

**特殊处理**：
- 日柱的十神固定为 `"日主"`

### 五、前端使用示例

前端可以直接使用这些新字段来渲染专业的排盘界面：

```vue
<template>
  <!-- 年柱 -->
  <view class="pillar-column">
    <view class="pillar-header">年柱</view>
    
    <!-- 十神 -->
    <view class="shishen-cell">
      <text>{{ baziData.year_pillar.shishen }}</text>
    </view>
    
    <!-- 天干 -->
    <view class="gan-cell">
      <text>{{ baziData.year_pillar.gan }}</text>
    </view>
    
    <!-- 地支 -->
    <view class="zhi-cell">
      <text>{{ baziData.year_pillar.zhi }}</text>
    </view>
    
    <!-- 藏干 -->
    <view class="canggan-cell">
      <text v-for="(gan, index) in baziData.year_pillar.canggan" :key="index">
        {{ gan }}
      </text>
    </view>
    
    <!-- 藏干十神 -->
    <view class="canggan-shishen-cell">
      <text v-for="(ss, index) in baziData.year_pillar.canggan_shishen" :key="index">
        {{ ss }}
      </text>
    </view>
    
    <!-- 十二长生 -->
    <view class="changsheng-cell">
      <text>{{ baziData.year_pillar.changsheng }}</text>
    </view>
    
    <!-- 纳音 -->
    <view class="nayin-cell">
      <text>{{ baziData.year_pillar.nayin }}</text>
    </view>
  </view>
</template>
```
