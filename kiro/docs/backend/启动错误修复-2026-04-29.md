## 错误 1：loadHistory 方法不存在

### 错误信息

```
TypeError: baziStore.loadHistory is not a function
at App.vue:81
```

### 问题原因

`App.vue` 中调用了 `baziStore.loadHistory()`，但 `useBaziStore` 中实际的方法名是 `loadFromLocalStorage()`。

### 修复方案

**文件**: `my-bazi-app/src/App.vue`

**修改前**:
```typescript

  // ...
  baziStore.loadHistory();  // ❌ 方法名错误
});
```

**修改后**:
```typescript
onLaunch(() => {
  // ...
  baziStore.loadFromLocalStorage();  // ✅ 正确的方法名
});
```

### 验证

```typescript

  // ...
```

## 错误 2：version.json 请求失败

### 错误信息

```
SyntaxError: Unexpected token < in JSON at position 0
checkUpdate @ App.vue:118
```

### 问题原因

1. `version.json` 文件不存在或路径错误
2. 请求返回了 HTML（404 页面）而不是 JSON
3. 缺少错误处理，导致 JSON 解析失败

### 修复方案

**文件**: `my-bazi-app/src/App.vue`

**修改内容**: 添加完善的错误处理

```typescript
async function checkUpdate() {
  try {
    const timestamp = new Date().getTime();
    const response = await fetch(`/version.json?t=${timestamp}`);
    
    // ✅ 检查响应状态
    if (!response.ok) {
      console.warn('⚠️ [版本检测] version.json 文件不存在或无法访问');
      return;
    }
    
    // ✅ 检查响应类型
    const contentType = response.headers.get('content-type');
    if (!contentType || !contentType.includes('application/json')) {
      console.warn('⚠️ [版本检测] version.json 返回的不是 JSON 格式');
      return;
    }
    
    const data = await response.json();
    // ... 后续逻辑
  } catch (error) {
    console.error('❌ [版本检测] 检查版本更新失败:', error);
    // ✅ 静默失败，不影响应用正常使用
  }
}
```

### 关键改进

1. **响应状态检查**: 检查 `response.ok`，如果是 404 则提前返回
2. **内容类型检查**: 验证返回的是 JSON 而不是 HTML
3. **友好的错误日志**: 使用 `console.warn` 而不是 `console.error`
4. **静默失败**: 不影响应用正常启动和使用

3. **服务器配置**: 确保开发服务器正确提供静态文件
