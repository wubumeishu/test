```python
@dataclass
class Pillar:
    """四柱（年月日时）"""
    gan: str        # 天干
    zhi: str        # 地支
    nayin: str      # 纳音
    canggan: List[str]  # 藏干
    shishen: str = ""  # 十神
    changsheng: str = ""  # 十二长生
    canggan_shishen: List[str] = None  # 藏干十神
    shensha: List[str] = None  # 神煞（新增）
    
    def __post_init__(self):
        """初始化后处理"""
        if self.canggan_shishen is None:
            self.canggan_shishen = []
        if self.shensha is None:
            self.shensha = []
```

#### 2.2 添加神煞提取函数

```python
def extract_shensha(lunar_obj, pillar_type: str) -> List[str]:
    """
    提取神煞列表
    
    Args:
        lunar_obj: Lunar 对象
        pillar_type: 柱类型 ('year', 'month', 'day', 'time')
        
    Returns:
        神煞名称列表
    """
    shensha_list = []
    
    try:
        if pillar_type == 'day':
            # 日柱神煞：吉神 + 凶煞 + 天神
            ji_shen = lunar_obj.getDayJiShen()  # 吉神列表
            xiong_sha = lunar_obj.getDayXiongSha()  # 凶煞列表
            tian_shen = lunar_obj.getDayTianShen()  # 天神
            
            if ji_shen:
                shensha_list.extend(ji_shen)
            if xiong_sha:
                shensha_list.extend(xiong_sha)
            if tian_shen and tian_shen not in shensha_list:
                shensha_list.append(tian_shen)
                
        elif pillar_type == 'time':
            # 时柱神煞：天神
            tian_shen = lunar_obj.getTimeTianShen()
            if tian_shen:
                shensha_list.append(tian_shen)
        
        # 年柱和月柱：lunar-python 未提供专门的神煞方法，返回空列表
        
    except Exception as e:
        print(f"⚠️ [神煞提取] {pillar_type}柱神煞提取失败: {e}")
    
    return shensha_list
```

## 📊 神煞数据说明

### lunar-python 提供的神煞方法

| 方法 | 返回类型 | 说明 |
|------|----------|------|
| `lunar.getDayJiShen()` | `List[str]` | 日柱吉神列表 |
| `lunar.getDayXiongSha()` | `List[str]` | 日柱凶煞列表 |
| `lunar.getDayTianShen()` | `str` | 日柱天神 |
| `lunar.getTimeTianShen()` | `str` | 时柱天神 |

## 📚 lunar-python 神煞说明

### 日柱神煞

lunar-python 为日柱提供了丰富的神煞信息：

1. **吉神（getDayJiShen）**
   - 月德：月德贵人
   - 天恩：天恩贵人
   - 时德：时德贵人
   - 阴德：阴德贵人
   - 福生：福生贵人
   - 司命：司命贵人

2. **凶煞（getDayXiongSha）**
   - 月煞：月煞凶神
   - 月虚：月虚凶神
   - 血支：血支凶神
   - 五虚：五虚凶神

3. **天神（getDayTianShen）**
   - 黄道吉神：司命、青龙、明堂、金匮、天德、玉堂
   - 黑道凶神：天刑、朱雀、白虎、天牢、玄武、勾陈

### 时柱神煞

lunar-python 为时柱提供天神信息：

- **天神（getTimeTianShen）**
  - 与日柱天神类似
  - 用于判断时辰吉凶

### 年柱和月柱

lunar-python 未提供年柱和月柱的专门神煞方法，可以根据需要扩展自定义计算逻辑。

## 📝 注意事项

1. **数据来源限制**
   - lunar-python 主要提供日柱和时柱的神煞
   - 年柱和月柱返回空列表
   - 可根据需要扩展自定义计算

2. **神煞数量**
   - 日柱神煞数量较多（通常 5-15 个）
   - 时柱神煞数量较少（通常 1-3 个）
   - 前端展示时需要考虑空间布局

3. **向后兼容**
   - 所有新增字段均为 Optional
   - 不影响现有功能
   - 历史数据自动填充空列表
