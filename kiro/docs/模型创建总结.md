## 技术特点

### 1. SQLAlchemy 2.0 现代语法
使用 `Mapped` 和 `mapped_column`:
```python
user_id: Mapped[str] = mapped_column(
    UUID(as_uuid=False),
    primary_key=True,
    default=lambda: str(uuid4()),
    comment="用户ID (UUID)"
)
```

### 2. UUID 主键
所有表使用 UUID 作为主键，字符串格式存储:
```python
from uuid import uuid4
default=lambda: str(uuid4())
```

### 3. JSONB 类型
使用 PostgreSQL 的 JSONB 类型存储 JSON 数据:
```python
five_elements_json: Mapped[Optional[dict]] = mapped_column(
    JSONB,
    nullable=True,
    comment="五行分析 JSON 数据"
)
```

### 4. 时间戳字段
支持本地和云端同步的时间戳:
```python
local_created_at: Mapped[int] = mapped_column(
    BigInteger,
    nullable=False,
    comment="本地创建时间戳 (毫秒)"
)
```

### 5. 级联删除
配置了级联删除规则:
```python
ForeignKey("users.user_id", ondelete="CASCADE")
```

### 6. 关联关系
使用 SQLAlchemy 的 relationship:
```python
archives: Mapped[list["Archive"]] = relationship(
    "Archive",
    back_populates="user",
    cascade="all, delete-orphan"
)
```
