### 3. 环境检查脚本

创建环境检查脚本:

```python
# kiro/scripts/check_environment.py

import sys
import subprocess
import os

def check_python_version():
    """检查 Python 版本"""
    version = sys.version_info
    if version.major >= 3 and version.minor >= 10:
        print(f"✅ Python 版本: {version.major}.{version.minor}.{version.micro}")
        return True
    else:
        print(f"❌ Python 版本过低: {version.major}.{version.minor}.{version.micro}")
        print("   需要 Python 3.10+")
        return False

def check_node_version():
    """检查 Node.js 版本"""
    try:
        result = subprocess.run(['node', '--version'], capture_output=True, text=True)
        version = result.stdout.strip()
        print(f"✅ Node.js 版本: {version}")
        return True
    except FileNotFoundError:
        print("❌ Node.js 未安装")
        return False

def check_postgresql():
    """检查 PostgreSQL"""
    try:
        result = subprocess.run(['psql', '--version'], capture_output=True, text=True)
        version = result.stdout.strip()
        print(f"✅ PostgreSQL: {version}")
        return True
    except FileNotFoundError:
        print("❌ PostgreSQL 未安装或未添加到 PATH")
        return False

def check_dependencies():
    """检查依赖"""
    print("\n📦 检查后端依赖...")
    if os.path.exists('bazi-admin/requirements.txt'):
        print("✅ requirements.txt 存在")
    else:
        print("❌ requirements.txt 不存在")
    
    print("\n📦 检查前端依赖...")
    if os.path.exists('my-bazi-app/package.json'):
        print("✅ package.json 存在")
    else:
        print("❌ package.json 不存在")

if __name__ == '__main__':
    print("🔍 环境检查\n")
    
    all_ok = True
    all_ok &= check_python_version()
    all_ok &= check_node_version()
    all_ok &= check_postgresql()
    check_dependencies()
    
    print("\n" + "="*50)
    if all_ok:
        print("✅ 环境检查通过!")
    else:
        print("❌ 环境检查失败，请安装缺失的依赖")
```

## 问题 3: ES 模块导入错误

**时间**: 2026-04-28 00:50

### 错误信息

```
useBaziStore.ts:9 Uncaught SyntaxError: The requested module '/src/utils/request.ts' does not provide an export named 'default' (at useBaziStore.ts:9:8)
```

### 问题原因

**导入/导出不匹配**:
- `useBaziStore.ts` 使用了**默认导入**: `import request from '../utils/request'`
- `request.ts` 只有**命名导出**: `export function get()`, `export function post()`
- 缺少**默认导出**: `export default function request()`

### 解决方案

修改 `request.ts`,添加默认导出:

**修改前**:
```typescript
function request<T = any>(
  method: 'GET' | 'POST' | 'PUT' | 'DELETE',
  config: RequestConfig
): Promise<T> {
  // ...
}
```

**修改后**:
```typescript
export default function request<T = any>(config: {
  url: string
  method: 'GET' | 'POST' | 'PUT' | 'DELETE'
  data?: any
  header?: any
  timeout?: number
}): Promise<T> {
  // ...
}
```

### 验证结果

- ✅ 前端服务重新编译成功
- ✅ 浏览器控制台无错误
- ✅ 模块导入正常

### 知识点

**ES 模块导入/导出**:

1. **默认导出** (Default Export):
   ```typescript
   export default function myFunc() { ... }
   import myFunc from './module'  // 可以使用任意名称
   ```

2. **命名导出** (Named Export):
   ```typescript
   export function myFunc() { ... }
   import { myFunc } from './module'  // 必须使用相同名称
   ```

3. **混合导出**:
   ```typescript
   export default function main() { ... }
   export function helper() { ... }
   import main, { helper } from './module'
   ```

### 预防措施

1. 创建了详细的文档: `kiro/docs/frontend/模块导入错误修复.md`
2. 统一项目中的导入/导出风格
3. 使用 TypeScript 进行类型检查
4. 在代码审查中注意导入/导出的一致性
