# 网络请求失败 - 快速修复指南

## 问题

前端排盘时出现 `request:fail` 错误。

## 原因

H5 项目必须在**浏览器**中运行，不能在微信开发者工具中运行。

## 解决步骤

### 1. 确认后端服务正在运行

打开终端，检查后端服务：

```bash
# 检查 9000 端口
netstat -ano | findstr :9000
```

如果没有输出，启动后端服务：

```bash
cd bazi-admin
python main.py
```

### 2. 确认前端服务正在运行

检查前端服务：

```bash
# 检查 5173 端口
netstat -ano | findstr :5173
```

如果没有输出，启动前端服务：

```bash
cd my-bazi-app
npm run dev:h5
```

### 3. 在浏览器中访问（重要！）

**不要在微信开发者工具中访问！**

1. 打开浏览器（Chrome、Edge、Firefox 等）
2. 访问 `http://localhost:5173`
3. 打开浏览器控制台（按 F12）
4. 切换到 Console 标签，查看日志
5. 切换到 Network 标签，查看网络请求

### 4. 测试排盘功能

1. 在浏览器中打开应用
2. 点击「排盘信息」
3. 切换到「快速排盘」标签
4. 填写信息：
   - 姓名：测试
   - 性别：男
   - 出生日期：2026-04-29
   - 出生时间：19:54
5. 点击「开始排盘」
6. 查看控制台日志和网络请求

### 5. 验证成功

如果修复成功，控制台应该显示：

```
🔄 [useBaziStore] 开始排盘 (通过原始数据)
📤 [useBaziStore] 请求参数: {...}
📥 [useBaziStore] 后端响应: {...}
✅ [useBaziStore] 排盘成功
```

Network 标签应该显示：
- URL: `http://localhost:5173/api/fortune/calculate-by-data`
- Status: `200 OK`
- Type: `xhr`

## 常见问题

### Q: 为什么不能在微信开发者工具中运行？

A: 微信开发者工具主要用于小程序开发，其网络环境与浏览器不同。H5 项目的 Vite 代理配置在微信开发者工具中不生效，会导致网络请求失败。

### Q: 如何在微信开发者工具中测试？

A: 如果必须在微信开发者工具中测试，需要：
1. 修改 `my-bazi-app/src/utils/request.ts`
2. 将 `baseURL` 改为 `http://127.0.0.1:9000`（直接访问后端）
3. 但这样会失去代理的好处，不推荐

### Q: 生产环境怎么办？

A: 生产环境中：
1. 前端打包后部署到服务器
2. 配置 Nginx 反向代理，将 `/api` 请求转发到后端
3. 或者前后端部署在同一域名下
