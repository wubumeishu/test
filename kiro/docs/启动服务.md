# 🚀 服务启动指南

## ⚠️ 重要提示

**后端服务必须在 `bazi-admin` 目录下启动!**

如果在项目根目录 `G:\2\` 启动会报错:
```
ERROR: Error loading ASGI app. Could not import module "main".
```

---

## ✅ 正确的启动方式

### 方法一: 使用 cd 命令

```bash
# 1. 切换到后端目录
cd bazi-admin

# 2. 启动后端服务
uvicorn main:app --host 127.0.0.1 --port 9000 --reload
```

### 方法二: 使用完整路径

```bash
# 在项目根目录执行
cd G:\2\bazi-admin && uvicorn main:app --host 127.0.0.1 --port 9000 --reload
```

### 方法三: 使用启动脚本 (推荐)

**Windows (PowerShell)**:
```powershell
# 创建启动脚本: start-backend.ps1
Set-Location -Path "G:\2\bazi-admin"
uvicorn main:app --host 127.0.0.1 --port 9000 --reload
```

执行:
```powershell
.\start-backend.ps1
```

**Windows (批处理)**:
```batch
# 创建启动脚本: start-backend.bat
@echo off
cd /d G:\2\bazi-admin
uvicorn main:app --host 127.0.0.1 --port 9000 --reload
```

执行:
```batch
start-backend.bat
```

## 🔍 常见错误及解决方案

### 错误 1: Could not import module "main"

**错误信息**:
```
ERROR: Error loading ASGI app. Could not import module "main".
```

**原因**: 在错误的目录下启动服务

**解决**: 
```bash
cd bazi-admin
uvicorn main:app --host 127.0.0.1 --port 9000 --reload
```

### 错误 2: Address already in use

**错误信息**:
```
ERROR: [Errno 10048] error while attempting to bind on address ('127.0.0.1', 9000): 通常每个套接字地址(协议/网络地址/端口)只允许使用一次。
```

**原因**: 端口 9000 已被占用

**解决**:
```bash
# 查找占用端口的进程
netstat -ano | findstr :9000

# 结束进程 (替换 PID 为实际进程ID)
taskkill /F /PID <PID>

# 或使用其他端口
uvicorn main:app --host 127.0.0.1 --port 9001 --reload
```

### 错误 3: ModuleNotFoundError

**错误信息**:
```
ModuleNotFoundError: No module named 'fastapi'
```

**原因**: 依赖未安装

**解决**:
```bash
cd bazi-admin
pip install -r requirements.txt
```

### 错误 4: Database connection failed

**错误信息**:
```
sqlalchemy.exc.OperationalError: could not connect to server
```

**原因**: PostgreSQL 未启动或配置错误

**解决**:
1. 检查 PostgreSQL 是否运行
2. 检查 `.env` 配置:
```env
DATABASE_URL=postgresql+asyncpg://postgres:password@localhost:5433/zen_bazi
```

## 📝 开发建议

### 1. 使用多个终端

- **终端 1**: 运行后端服务
- **终端 2**: 运行前端服务
- **终端 3**: 执行测试脚本

### 2. 使用 VS Code 集成终端

在 VS Code 中:
1. 打开集成终端 (Ctrl + `)
2. 点击 `+` 创建新终端
3. 在不同终端中运行不同服务

### 3. 使用 tmux/screen (Linux/Mac)

```bash
# 创建会话
tmux new -s bazi

# 分割窗口
Ctrl+B %  # 垂直分割
Ctrl+B "  # 水平分割

# 切换窗口
Ctrl+B 方向键
```

### 4. 使用 Docker Compose (高级)

创建 `docker-compose.yml`:
```yaml
version: '3.8'
services:
  backend:
    build: ./bazi-admin
    ports:
      - "9000:9000"
    environment:
      - DATABASE_URL=postgresql+asyncpg://postgres:password@db:5432/zen_bazi
  
  frontend:
    build: ./my-bazi-app
    ports:
      - "5173:5173"
  
  db:
    image: postgres:14
    environment:
      - POSTGRES_PASSWORD=password
      - POSTGRES_DB=zen_bazi
    ports:
      - "5433:5432"
```

启动:
```bash
docker-compose up
```
