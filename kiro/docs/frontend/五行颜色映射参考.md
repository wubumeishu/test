## 💻 代码实现

### TypeScript 函数

```typescript
const getWuxingColor = (char: string): string => {
  const colors = {
    wood: '#4CAF50',   // 木：绿色
    fire: '#E53935',   // 火：红色
    earth: '#8D6E63',  // 土：褐色
    metal: '#D4AF37',  // 金：金色
    water: '#1E88E5'   // 水：蓝色
  }
  
  const wuxingMap: Record<string, string> = {
    // 木
    '甲': colors.wood, '乙': colors.wood, '寅': colors.wood, '卯': colors.wood,
    // 火
    '丙': colors.fire, '丁': colors.fire, '巳': colors.fire, '午': colors.fire,
    // 土
    '戊': colors.earth, '己': colors.earth, 
    '辰': colors.earth, '戌': colors.earth, '丑': colors.earth, '未': colors.earth,
    // 金
    '庚': colors.metal, '辛': colors.metal, '申': colors.metal, '酉': colors.metal,
    // 水
    '壬': colors.water, '癸': colors.water, '亥': colors.water, '子': colors.water
  }
  
  return wuxingMap[char] || '#333333'
}
```

## 🎨 颜色选择原则

### 1. 传统认知

- **木**：绿色 - 代表生机、生长、春天
- **火**：红色 - 代表热情、炎热、夏天
- **土**：褐色 - 代表厚重、稳定、大地
- **金**：金色 - 代表坚硬、锐利、金属
- **水**：蓝色 - 代表流动、灵活、水流

### 2. 视觉和谐

- 饱和度适中，不过于刺眼
- 与禅意背景（米白色）和谐统一
- 保持专业性，避免过于花哨

### 3. 可读性

- 颜色对比度足够，易于识别
- 不同五行颜色区分明显
- 在白色和浅色背景上清晰可见

  // 阳干：原色

  const yangGan = ['甲', '丙', '戊', '庚', '壬']

## 📝 注意事项

1. **日主优先级**：日柱天干始终使用朱砂红，不使用五行颜色
2. **默认颜色**：未匹配到的字符使用深灰色 `#333333`
3. **辅助信息**：十神、长生、纳音保持灰色，不使用五行颜色
4. **颜色一致性**：同一个字在不同位置使用相同颜色
