# 模块导入错误修复

## 问题描述

**时间**: 2026-04-28 00:50

**错误信息**:
```
useBaziStore.ts:9 Uncaught SyntaxError: The requested module '/src/utils/request.ts' does not provide an export named 'default' (at useBaziStore.ts:9:8)
```

**错误位置**: `my-bazi-app/src/store/useBaziStore.ts` 第 9 行

---

## 问题原因

### ES 模块导入/导出不匹配

**useBaziStore.ts** (第 9 行):
```typescript
import request from '../utils/request'  // ❌ 默认导入
```

**request.ts** (原始代码):
```typescript
function request<T = any>(...) { ... }  // ❌ 没有默认导出

export function get<T = any>(...) { ... }
export function post<T = any>(...) { ... }
// 只有命名导出
```

**问题**: 
- `useBaziStore.ts` 使用了**默认导入** (`import request from ...`)
- 但 `request.ts` 只有**命名导出** (`export function ...`)
- 没有**默认导出** (`export default ...`)

---

## 解决方案

### 方案一: 修改 request.ts 添加默认导出 (已采用)

**修改前**:
```typescript
function request<T = any>(
  method: 'GET' | 'POST' | 'PUT' | 'DELETE',
  config: RequestConfig
): Promise<T> {
  // ...
}
```

**修改后**:
```typescript
export default function request<T = any>(config: {
  url: string
  method: 'GET' | 'POST' | 'PUT' | 'DELETE'
  data?: any
  header?: any
  timeout?: number
}): Promise<T> {
  // ...
}
```

**优点**:
- ✅ 不需要修改 `useBaziStore.ts`
- ✅ 保持原有的导入方式
- ✅ 更符合常见的使用习惯

**缺点**:
- ⚠️ 需要调整函数签名 (合并参数)

### 方案二: 修改 useBaziStore.ts 使用命名导入 (备选)

**修改前**:
```typescript
import request from '../utils/request'
```

**修改后**:
```typescript
import { post } from '../utils/request'

// 使用时
const response = await post<BaziCalculateResponse>('/api/fortune/calculate', {
  archive_id: archiveId,
  is_deep_analysis: isDeepAnalysis
})
```

**优点**:
- ✅ 不需要修改 `request.ts`
- ✅ 更明确地表示使用哪个方法

**缺点**:
- ⚠️ 需要修改所有使用 `request` 的地方
- ⚠️ 代码改动较大

## 修复步骤

### 1. 修改 request.ts

**位置**: `my-bazi-app/src/utils/request.ts`

**修改内容**:

```typescript
/**
 * 通用请求方法 (默认导出)
 */
export default function request<T = any>(config: {
  url: string
  method: 'GET' | 'POST' | 'PUT' | 'DELETE'
  data?: any
  header?: any
  timeout?: number
}): Promise<T> {
  return new Promise((resolve, reject) => {
    uni.request({
      url: `${baseURL}${config.url}`,
      method: config.method,
      data: config.data,
      header: {
        'Content-Type': 'application/json',
        ...config.header,
      },
      timeout: config.timeout || 10000,
      success: (res: ResponseData<T>) => {
        if (res.statusCode >= 200 && res.statusCode < 300) {
          resolve(res.data)
        } else {
          console.error('请求失败:', res)
          reject(new Error(`请求失败: ${res.statusCode}`))
        }
      },
      fail: (err) => {
        console.error('网络请求错误:', err)
        reject(err)
      },
    })
  })
}
```

### 2. 更新辅助函数

**位置**: `my-bazi-app/src/utils/request.ts`

**修改内容**:

```typescript
/**
 * GET 请求
 */
export function get<T = any>(url: string, data?: any, config?: Partial<RequestConfig>): Promise<T> {
  return request<T>({
    url,
    method: 'GET',
    data,
    ...config,
  })
}

/**
 * POST 请求
 */
export function post<T = any>(url: string, data?: any, config?: Partial<RequestConfig>): Promise<T> {
  return request<T>({
    url,
    method: 'POST',
    data,
    ...config,
  })
}

// PUT 和 DELETE 同理...
```

### 3. 重启前端服务

```bash
# 停止服务 (Ctrl+C)
# 重新启动
cd my-bazi-app
npm run dev:h5
```

### 4. 验证修复

访问 http://localhost:5173 ,检查控制台是否还有错误。

## ES 模块导入/导出知识点

### 默认导出 (Default Export)

**导出**:
```typescript
// 方式 1: 直接导出
export default function myFunction() { ... }

// 方式 2: 先定义后导出
function myFunction() { ... }
export default myFunction

// 方式 3: 导出表达式
export default { name: 'test', value: 123 }
```

**导入**:
```typescript
// 可以使用任意名称
import myFunc from './module'
import whatever from './module'  // 名称可以不同
```

### 命名导出 (Named Export)

**导出**:
```typescript
// 方式 1: 直接导出
export function func1() { ... }
export const value1 = 123

// 方式 2: 先定义后导出
function func1() { ... }
const value1 = 123
export { func1, value1 }

// 方式 3: 重命名导出
export { func1 as myFunc, value1 as myValue }
```

**导入**:
```typescript
// 必须使用相同的名称
import { func1, value1 } from './module'

// 重命名导入
import { func1 as myFunc } from './module'

// 导入所有
import * as myModule from './module'
myModule.func1()
```

### 混合导出

**导出**:
```typescript
// 同时有默认导出和命名导出
export default function main() { ... }
export function helper1() { ... }
export function helper2() { ... }
export const config = { ... }
```

**导入**:
```typescript
// 导入默认和命名
import main, { helper1, helper2, config } from './module'

// 分开导入
import main from './module'
import { helper1 } from './module'
```

## 常见错误

### 错误 1: 默认导入不存在的默认导出

```typescript
// module.ts
export function myFunc() { ... }  // 只有命名导出

// main.ts
import myFunc from './module'  // ❌ 错误: 没有默认导出
```

**解决**:
```typescript
// 方法 1: 使用命名导入
import { myFunc } from './module'

// 方法 2: 添加默认导出
export default function myFunc() { ... }
```

### 错误 2: 命名导入不存在的导出

```typescript
// module.ts
export default function myFunc() { ... }  // 只有默认导出

// main.ts
import { myFunc } from './module'  // ❌ 错误: 没有命名导出
```

**解决**:
```typescript
// 方法 1: 使用默认导入
import myFunc from './module'

// 方法 2: 添加命名导出
export function myFunc() { ... }
export default myFunc
```

### 错误 3: 导入名称拼写错误

```typescript
// module.ts
export function myFunction() { ... }

// main.ts
import { myFunc } from './module'  // ❌ 错误: 名称不匹配
```

**解决**:
```typescript
// 使用正确的名称
import { myFunction } from './module'

// 或使用重命名
import { myFunction as myFunc } from './module'
```

## 最佳实践

### 1. 选择合适的导出方式

**默认导出** - 适用于:
- ✅ 模块只有一个主要功能
- ✅ 工具函数库的主函数
- ✅ React/Vue 组件

**命名导出** - 适用于:
- ✅ 模块有多个功能
- ✅ 工具函数集合
- ✅ 常量和配置

### 2. 保持一致性

在同一个项目中,尽量保持导入/导出风格的一致性:

```typescript
// 推荐: 统一使用命名导出
export function func1() { ... }
export function func2() { ... }
export const config = { ... }

// 或: 主函数用默认导出,辅助函数用命名导出
export default function main() { ... }
export function helper1() { ... }
export function helper2() { ... }
```

### 3. 避免循环依赖

```typescript
// ❌ 避免
// a.ts
import { funcB } from './b'
export function funcA() { funcB() }

// b.ts
import { funcA } from './a'
export function funcB() { funcA() }
```

### 4. 使用 TypeScript 类型导出

```typescript
// types.ts
export interface User {
  id: string
  name: string
}

export type UserRole = 'admin' | 'user'

// main.ts
import type { User, UserRole } from './types'
// 或
import { type User, type UserRole } from './types'
```
