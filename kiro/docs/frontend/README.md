## 🎨 设计规范

### 毛玻璃禅意风格
- 背景：`rgba(20, 20, 20, 0.6)`
- 模糊：`backdrop-filter: blur(15px)`
- 边框：极细金/白色边框
- 字体：霜白色 `rgba(255, 255, 255, 0.85)`
