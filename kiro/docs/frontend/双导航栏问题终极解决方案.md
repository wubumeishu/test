# 双导航栏问题终极解决方案

## 🐛 问题描述

项目中底部出现了两个导航栏：
1. 原生 TabBar（系统默认）
2. 自定义 ZenTabBar（毛玻璃效果）

## 🔍 问题分析

### 原因1：pages.json 配置不完整
`tabBar.custom` 必须设置为 `true`，但这还不够。

### 原因2：非 TabBar 页面显示了 ZenTabBar
某些不在 `tabBar.list` 中的页面（如 setup、result、add）错误地引入了 `ZenTabBar` 组件。

### 原因3：原生 TabBar 未被强制隐藏
某些平台在页面切换时会重新显示原生 TabBar。

## ✅ 完整解决方案

### 1. pages.json 配置

确保 `tabBar.custom` 设置为 `true`：

```json
{
  "tabBar": {
    "custom": true,  // ✅ 必须设置
    "color": "#999999",
    "selectedColor": "#B23A34",
    "backgroundColor": "#F9F6F1",
    "borderStyle": "white",
    "list": [
      {
        "pagePath": "pages/index/index",
        "text": "首页"
      },
      {
        "pagePath": "pages/questions/questions",
        "text": "解惑"
      },
      {
        "pagePath": "pages/zen/zen",
        "text": "禅修"
      },
      {
        "pagePath": "pages/mine/mine",
        "text": "我的"
      }
    ]
  }
}
```

### 2. App.vue 全局隐藏逻辑

在 `App.vue` 中添加强制隐藏逻辑：

```typescript
<script setup lang="ts">
import { onLaunch, onShow } from "@dcloudio/uni-app";

/**
 * 隐藏原生 TabBar
 */
const hideNativeTabBar = () => {
  uni.hideTabBar({
    animation: false,
    success: () => console.log('✅ 原生 TabBar 已隐藏'),
    fail: (err) => console.log('⚠️ 隐藏 TabBar 失败或当前不在 TabBar 页面', err)
  });
};

/**
 * 强制隐藏原生 TabBar (多次尝试)
 */
const forceHideNativeTabBar = () => {
  // 立即执行一次
  hideNativeTabBar();
  
  // 50ms 后再执行一次
  setTimeout(() => {
    hideNativeTabBar();
  }, 50);
  
  // 100ms 后再执行一次
  setTimeout(() => {
    hideNativeTabBar();
  }, 100);
};

onLaunch(() => {
  console.log("App Launch");
  forceHideNativeTabBar();
});

onShow(() => {
  console.log("App Show");
  forceHideNativeTabBar();
});
</script>
```

## 🎯 常见问题

### Q1: 为什么设置了 `custom: true` 还是显示原生 TabBar？

**A**: 某些平台需要在页面级别强制隐藏。在 `App.vue` 的 `onShow` 中多次调用 `uni.hideTabBar()` 可以解决。

### Q2: 为什么非 TabBar 页面也显示了导航栏？

**A**: 检查页面是否错误地引入了 `ZenTabBar` 组件。非 TabBar 页面不应该有任何导航栏组件。

### Q3: 为什么有时候显示一个，有时候显示两个？

**A**: 这是因为原生 TabBar 的显示/隐藏时机不稳定。使用多次延迟调用 `uni.hideTabBar()` 可以确保彻底隐藏。

### Q4: 如何添加新的 TabBar 页面？

**A**: 
1. 在 `pages.json` 的 `tabBar.list` 中添加页面路径
2. 在页面中引入 `ZenTabBar` 组件
3. 设置正确的 `current` 值

### Q5: 如何添加新的非 TabBar 页面？

**A**:
1. 在 `pages.json` 的 `pages` 数组中添加页面路径
2. **不要**在 `tabBar.list` 中添加
3. **不要**在页面中引入 `ZenTabBar` 组件
4. 在 `onMounted` 中调用 `uni.hideTabBar()`
