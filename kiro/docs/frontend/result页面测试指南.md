## ❌ 常见问题排查

### 问题 1：藏干显示为数组字符串

**症状：**
```
["丁", "己"]
```

**原因：** 模板中直接输出了数组

**解决：** 确保使用 `v-for` 循环遍历藏干数组

---

### 问题 2：四柱顺序错误

**症状：** 四柱顺序不是年月日时

**原因：** `pillarList` 数组顺序错误

**检查：** 查看 `<script setup>` 中的 `pillarList` 计算属性

---

### 问题 3：日主没有高亮

**症状：** 日柱的天干和"日主"文字不是朱砂红色

**原因：** 
1. `isDayMaster` 标记错误
2. CSS 类名绑定错误

**检查：**
```vue
:class="{ 'highlight': pillar.isDayMaster }"
```

---

### 问题 4：藏干十神对应错误

**症状：** 藏干和藏干十神数量不一致或对应关系错误

**原因：** 索引使用错误

**检查：**
```vue
<text class="cg-ss">
  {{ pillar.canggan_shishen[cgIndex] || '-' }}
</text>
```

---

### 问题 5：数据缺失

**症状：** 某些字段显示为空或 `-`

**原因：** 后端数据未正确返回

**解决：**
1. 检查后端 API 是否正确返回十神和长生数据
2. 运行后端测试脚本：`python kiro/scripts/test_fortune_api.py`

## 🔍 调试技巧

### 1. 浏览器控制台

打开浏览器开发者工具（F12），查看：
- Console：是否有 JavaScript 错误
- Network：API 请求是否成功
- Vue DevTools：查看 `pillarList` 数据结构

### 2. 打印调试

在 `<script setup>` 中添加：
```typescript
console.log('pillarList:', pillarList.value)
```

### 3. 检查 API 响应

在 Network 标签中找到 `/api/fortune/calculate-by-data` 请求，查看响应数据：
```json
{
  "year_pillar": {
    "gan": "庚",
    "zhi": "午",
    "shishen": "比肩",
    "changsheng": "沐浴",
    "canggan": ["丁", "己"],
    "canggan_shishen": ["正官", "正印"]
  }
}
```
