## 🎨 精修内容

### 1. 五行颜色映射

#### 1.1 添加颜色映射函数

在 `<script setup>` 中添加 `getWuxingColor` 函数：

```typescript
// 五行颜色映射
const getWuxingColor = (char: string): string => {
  const colors = {
    wood: '#4CAF50',   // 木：绿色
    fire: '#E53935',   // 火：红色
    earth: '#8D6E63',  // 土：褐色
    metal: '#D4AF37',  // 金：金色
    water: '#1E88E5'   // 水：蓝色
  }
  
  const wuxingMap: Record<string, string> = {
    // 木
    '甲': colors.wood, '乙': colors.wood, '寅': colors.wood, '卯': colors.wood,
    // 火
    '丙': colors.fire, '丁': colors.fire, '巳': colors.fire, '午': colors.fire,
    // 土
    '戊': colors.earth, '己': colors.earth, 
    '辰': colors.earth, '戌': colors.earth, '丑': colors.earth, '未': colors.earth,
    // 金
    '庚': colors.metal, '辛': colors.metal, '申': colors.metal, '酉': colors.metal,
    // 水
    '壬': colors.water, '癸': colors.water, '亥': colors.water, '子': colors.water
  }
  
  return wuxingMap[char] || '#333333' // 默认深灰
}
```

#### 1.2 颜色选择说明

| 五行 | 颜色代码 | 颜色名称 | 说明 |
|------|----------|----------|------|
| 木 | `#4CAF50` | 绿色 | 生机勃勃，代表生长 |
| 火 | `#E53935` | 红色 | 热情奔放，代表炎热 |
| 土 | `#8D6E63` | 褐色 | 厚重稳定，代表大地 |
| 金 | `#D4AF37` | 金色 | 坚硬锐利，代表金属 |
| 水 | `#1E88E5` | 蓝色 | 流动灵活，代表水流 |

**设计原则：**
- 颜色饱和度适中，不过于刺眼
- 符合传统五行色彩认知
- 与禅意背景和谐统一

#### 1.3 模板中应用颜色

**天干：**
```vue
<text 
  class="gan-text" 
  :class="{ 'highlight': pillar.isDayMaster }"
  :style="{ color: pillar.isDayMaster ? '#C0392B' : getWuxingColor(pillar.gan) }"
>
  {{ pillar.gan }}
</text>
```

**说明：**
- 日主天干优先使用朱砂红 `#C0392B`
- 其他天干使用五行对应颜色

**地支：**
```vue
<text 
  class="zhi-text"
  :style="{ color: getWuxingColor(pillar.zhi) }"
>
  {{ pillar.zhi }}
</text>
```

**藏干：**
```vue
<text 
  class="cg-text"
  :style="{ color: getWuxingColor(cg) }"
>
  {{ cg }}
</text>
```

### 2. 解决垂直错位问题

#### 2.1 问题分析

**原因：**
- 地支藏干数量不同（1-3个）
- `canggan-box` 高度由内容撑开
- 导致后续元素（长生、纳音）位置不对齐

**示例：**
```
年柱（2个藏干）  月柱（3个藏干）  日柱（3个藏干）  时柱（3个藏干）
    丁              丙              戊              己
   正官            七杀            偏印            正印
    己              庚              乙              丁
   正印            比肩            正财            正官
                    戊              癸              乙
                   偏印            伤官            正财
  ↓ 错位          ↓ 正常          ↓ 正常          ↓ 正常
  沐浴            长生             养             冠带
```

#### 2.2 解决方案

**核心思路：** 固定 `canggan-box` 高度，确保所有柱子的藏干区域高度一致。

**CSS 修改：**

```css
/* 藏干容器 - 固定高度解决错位问题 */
.canggan-cell {
  padding: 12rpx 8rpx;
  min-height: 180rpx; /* 确保容纳3行藏干 */
}

.canggan-box {
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: flex-start;
  height: 140rpx; /* 强制固定高度，确保能容纳3行小字且底部留白 */
  margin: 10rpx 0;
  gap: 4rpx;
}

.cg-item {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 8rpx;
  height: 40rpx; /* 每行藏干固定高度 */
  width: 100%;
}
```

**关键参数：**
- `canggan-box` 高度：`140rpx`（可容纳 3 行 × 40rpx + 间距）
- 每行藏干高度：`40rpx`
- 对齐方式：`justify-content: flex-start`（从顶部开始排列）

#### 2.3 其他元素固定高度

为了确保整体对齐，长生和纳音也设置固定高度：

```css
/* 十二长生 - 固定高度 */
.changsheng-text {
  display: block;
  height: 40rpx;
  line-height: 40rpx;
  font-size: 22rpx;
  color: #666;
}

/* 纳音 - 固定高度 */
.nayin-text {
  display: block;
  height: 40rpx;
  line-height: 40rpx;
  font-size: 20rpx;
  color: #8E8E93;
}
```

## 🔑 关键技术点

### 1. 动态样式绑定

使用 `:style` 动态绑定颜色：

```vue
:style="{ color: getWuxingColor(pillar.gan) }"
```

**优势：**
- 灵活性高，可根据数据动态计算
- 不需要为每个干支创建单独的 CSS 类
- 易于维护和扩展

### 2. 条件颜色优先级

日主天干的颜色处理：

```vue
:style="{ color: pillar.isDayMaster ? '#C0392B' : getWuxingColor(pillar.gan) }"
```

**逻辑：**
- 如果是日主 → 使用朱砂红（优先级最高）
- 否则 → 使用五行对应颜色

### 3. 固定高度布局

```css
.canggan-box {
  height: 140rpx; /* 固定高度 */
  justify-content: flex-start; /* 从顶部开始 */
}
```

**原理：**
- 固定容器高度，不受内容影响
- 内容从顶部开始排列
- 底部自动留白

---

## 📝 CSS 关键参数说明

| 元素 | 参数 | 值 | 说明 |
|------|------|-----|------|
| `canggan-box` | `height` | `140rpx` | 固定高度，容纳3行藏干 |
| `cg-item` | `height` | `40rpx` | 每行藏干高度 |
| `changsheng-text` | `height` | `40rpx` | 长生文字高度 |
| `nayin-text` | `height` | `40rpx` | 纳音文字高度 |
| `canggan-cell` | `min-height` | `180rpx` | 藏干单元格最小高度 |

**计算逻辑：**
```
canggan-box 高度 = 3行 × 40rpx + 间距 ≈ 140rpx
canggan-cell 最小高度 = 140rpx + padding ≈ 180rpx
```
