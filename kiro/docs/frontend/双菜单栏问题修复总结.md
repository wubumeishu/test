# 双菜单栏问题修复总结

## 问题描述

底部出现两个菜单栏：
1. 原生 TabBar（UniApp 自带）
2. 自定义毛玻璃 TabBar（ZenTabBar 组件）

## 问题原因

原生 TabBar 在页面切换时会自动"复活"，即使已经配置了 `custom: true`。

## 修复方案

### 1. pages.json 配置 ✅

**文件**: `my-bazi-app/src/pages.json`

**状态**: 已正确配置

```json
{
  "tabBar": {
    "custom": true,  // ✅ 已配置
    "list": [...]
  }
}
```

**验证**:
- ✅ `custom: true` 已设置
- ✅ 所有页面的 `navigationStyle` 都设置为 `custom`
- ✅ 没有页面意外开启原生标题栏

### 2. App.vue 强化隐藏逻辑 ✅

**文件**: `my-bazi-app/src/App.vue`

**状态**: 已实现强化隐藏

```typescript
// 强制隐藏原生 TabBar (多次尝试)
const forceHideNativeTabBar = () => {
  hideNativeTabBar();  // 立即执行
  setTimeout(() => hideNativeTabBar(), 50);   // 50ms 后
  setTimeout(() => hideNativeTabBar(), 100);  // 100ms 后
}

onLaunch(() => {
  forceHideNativeTabBar();  // ✅ 应用启动时隐藏
})

onShow(() => {
  forceHideNativeTabBar();  // ✅ 页面显示时隐藏
})
```

**特点**:
- ✅ 多次尝试隐藏（处理异步渲染）
- ✅ 在 `onLaunch` 和 `onShow` 中都执行
- ✅ 使用 `animation: false` 避免闪烁

### 3. ZenTabBar 组件加固 ✅

**文件**: `my-bazi-app/src/components/ZenTabBar/ZenTabBar.vue`

**修改内容**: 添加 `onMounted` 钩子

```typescript
import { defineProps, onMounted } from 'vue'

onMounted(() => {
  // #ifdef H5
  uni.hideTabBar({
    animation: false,
    success: () => console.log('✅ [ZenTabBar] 原生 TabBar 已强制隐藏'),
    fail: () => console.log('ℹ️ [ZenTabBar] 当前页面无原生 TabBar')
  })
  // #endif
})
```

**作用**:
- ✅ 组件挂载时再次隐藏原生 TabBar
- ✅ 防止页面切换时原生 TabBar 重新渲染
- ✅ 仅在 H5 平台执行（使用条件编译）

### 4. 路由跳转检查 ✅

**文件**: `my-bazi-app/src/components/ZenTabBar/ZenTabBar.vue`

## 常见问题

### Q1: 为什么需要多次隐藏？

**A**: 不同平台的渲染时机不同：
- 有些平台在 DOM 渲染前就可以隐藏
- 有些平台需要等待 DOM 渲染完成
- 多次尝试可以覆盖所有情况

### Q2: 为什么在 ZenTabBar 组件中也要隐藏？

**A**: 双重保险：
- `App.vue` 在全局层面隐藏
- `ZenTabBar` 在组件层面再次隐藏
- 防止页面切换时原生 TabBar "复活"

### Q3: 为什么只在 H5 平台执行？

**A**: 平台差异：
- H5 平台容易出现双菜单栏问题
- 小程序和 App 平台的 TabBar 管理机制不同
- 使用条件编译避免不必要的执行

### Q4: 如果仍然出现双菜单栏怎么办？

**A**: 排查步骤：

1. **检查 pages.json**
   ```json
   "tabBar": {
     "custom": true  // 必须为 true
   }
   ```

2. **检查浏览器控制台**
   - 查看是否有隐藏失败的日志
   - 查看是否有错误信息

3. **清除缓存**
   ```bash
   # 停止服务
   # 删除 node_modules/.vite 缓存
   rm -rf node_modules/.vite
   # 重新启动
   npm run dev:h5
   ```

4. **检查 CSS**
   - 确保自定义 TabBar 的 `z-index` 足够高
   - 确保没有其他元素遮挡
