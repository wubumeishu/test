# 档案编辑页面实现

## 更新时间
2026-04-29

## 概述
创建了档案新建与编辑页面 `src/pages/archive/add.vue`，支持新建和编辑两种模式，采用禅意设计风格，提供完整的表单验证和用户体验优化。

## 页面路径
- **路径**: `/pages/archive/add`
- **标题**: 编辑档案
- **导航**: 自定义导航栏，隐藏原生 TabBar

## 功能特性

### 1. 双模式支持

#### 新建模式
- 访问路径: `/pages/archive/add`
- 无需传递参数
- 表单为空，等待用户输入
- 提交按钮显示"保存档案"

#### 编辑模式
- 访问路径: `/pages/archive/add?id=档案ID`
- 通过 URL 参数 `id` 传递档案 ID
- 自动从 `useArchiveStore` 中查找对应档案
- 回显档案数据到表单
- 提交按钮显示"保存修改"
- 显示删除按钮

### 2. 页面状态判断逻辑

```typescript
onMounted(() => {
  // 获取页面参数
  const pages = getCurrentPages()
  const currentPage = pages[pages.length - 1] as any
  const options = currentPage.options || {}
  
  // 判断是否为编辑模式
  if (options.id) {
    isEditMode.value = true
    editArchiveId.value = options.id
    
    // 从 Store 中找出对应档案并回显数据
    const archive = archiveStore.archives.find(item => item.id === options.id)
    
    if (archive) {
      // 回显数据
      formData.name = archive.name
      formData.gender = archive.gender
      formData.birthDate = archive.birthDate
      formData.birthTime = archive.birthTime
      formData.relation = archive.relation || '本人'
      formData.isDefault = archive.isDefault
    }
  }
})
```

## 表单验证

### 验证规则
```typescript
const validateForm = (): boolean => {
  // 1. 姓名不能为空
  if (!formData.name.trim()) {
    uni.showToast({
      title: '请输入姓名',
      icon: 'none',
      duration: 1500
    })
    return false
  }

  // 2. 出生日期不能为空
  if (!formData.birthDate) {
    uni.showToast({
      title: '请选择出生日期',
      icon: 'none',
      duration: 1500
    })
    return false
  }

  // 3. 出生时间不能为空
  if (!formData.birthTime) {
    uni.showToast({
      title: '请选择出生时间',
      icon: 'none',
      duration: 1500
    })
    return false
  }

  return true
}
```

### 验证时机
- 点击提交按钮时进行验证
- 验证失败显示 Toast 提示
- 验证成功才执行保存操作

## 提交逻辑

### 新建模式
```typescript
// 1. 调用 addArchive 添加档案
const newArchive = await archiveStore.addArchive({
  name: formData.name.trim(),
  gender: formData.gender,
  birthDate: formData.birthDate,
  birthTime: formData.birthTime,
  relation: formData.relation,
  isDefault: formData.isDefault
})

// 2. 设置为当前档案
if (newArchive) {
  archiveStore.currentArchiveId = newArchive.id
}

// 3. 返回上一页
setTimeout(() => {
  uni.navigateBack()
}, 500)
```

### 编辑模式
```typescript
// 1. 调用 updateArchive 更新档案
await archiveStore.updateArchive(editArchiveId.value, {
  name: formData.name.trim(),
  gender: formData.gender,
  birthDate: formData.birthDate,
  birthTime: formData.birthTime,
  relation: formData.relation,
  isDefault: formData.isDefault
})

// 2. 设置为当前档案
archiveStore.currentArchiveId = editArchiveId.value

// 3. 返回上一页
setTimeout(() => {
  uni.navigateBack()
}, 500)
```

### 关键特性
- ✅ 保存成功后，将该档案设为 `currentArchiveId`
- ✅ 方便排盘功能直接使用当前档案
- ✅ 使用 `uni.navigateBack()` 返回上一页
- ✅ 延迟 500ms 返回，让用户看到成功提示

## 删除逻辑

### 确认对话框
```typescript
uni.showModal({
  title: '确认删除',
  content: '确定要删除这个档案吗？删除后无法恢复。',
  confirmText: '删除',
  confirmColor: '#B22222',
  cancelText: '取消',
  success: async (res) => {
    if (res.confirm) {
      // 执行删除
      const success = await archiveStore.deleteArchive(editArchiveId.value)
      
      if (success) {
        // 返回上一页
        setTimeout(() => {
          uni.navigateBack()
        }, 500)
      }
    }
  }
})
```

### 安全措施
- 弹出确认对话框，防止误删
- 删除按钮使用警告色（朱砂红）
- 提示"删除后无法恢复"

## 页面配置

### pages.json 配置
```json
{
  "path": "pages/archive/add",
  "style": {
    "navigationStyle": "custom",
    "navigationBarTitleText": "编辑档案",
    "enablePullDownRefresh": false
  }
}
```

### 配置说明
- `navigationStyle: "custom"`: 使用自定义导航栏
- `navigationBarTitleText`: 页面标题（用于分享等场景）
- `enablePullDownRefresh: false`: 禁用下拉刷新
- 原生 TabBar 自动隐藏（通过 `uni.hideTabBar()` 实现）

## 设计亮点

### 1. 毛玻璃效果
- 使用 `backdrop-filter: blur(10rpx)` 实现
- 配合渐变背景营造层次感
- 符合新中式禅意设计风格

### 2. 朱砂红主色调
- 选中状态使用朱砂红 `#8B2626`
- 浅红背景 `#FFF5F5` 作为辅助
- 传统吉祥色，符合八字排盘主题

### 3. 交互细节
- 按钮按下缩放效果
- 加载状态禁用按钮
- 表单验证即时反馈
- 删除操作二次确认

### 4. 文化元素
- 性别使用"乾造"、"坤造"传统术语
- 关系标签预设常用选项
- 时辰提示符合传统命理习惯

## 响应式适配

### 单位使用
- 使用 `rpx` 单位自动适配不同屏幕
- 1rpx = 屏幕宽度 / 750

### 兼容性
- 使用 `<view>` 替代 `<div>`
- 使用 `<text>` 替代 `<span>`
- 使用 `<input>` 原生组件
- 使用 `<picker>` 原生选择器
- 使用 Material Symbols 图标
