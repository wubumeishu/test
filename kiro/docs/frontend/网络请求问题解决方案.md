# 网络请求问题解决方案

## 问题描述

前端在排盘时出现 `request:fail` 错误：

```
❌ [useBaziStore] 排盘失败: {errMsg: "request:fail"}
❌ [useBaziStore] 错误详情: 排盘失败，请检查网络连接
```

## 诊断结果

✅ **所有后端服务运行正常**

通过诊断脚本确认：
- ✅ 后端服务正在运行（端口 9000）
- ✅ 前端服务正在运行（端口 5173）
- ✅ 后端健康检查接口正常
- ✅ 排盘接口正常
- ✅ CORS 已配置
- ✅ Vite 代理已配置

## 问题原因

**前端访问方式不正确**

`request:fail` 错误通常发生在以下情况：

1. **在微信开发者工具中运行 H5 项目**
   - 微信开发者工具的网络环境与浏览器不同
   - Vite 代理配置在微信开发者工具中不生效
   - 导致前端无法通过代理访问后端

2. **浏览器扩展或防火墙阻止请求**
   - 某些浏览器扩展可能阻止本地请求
   - 防火墙可能阻止端口访问

## 解决方案

### ✅ 方案 1：在浏览器中访问（推荐）

**这是最简单、最正确的方式！**

1. **打开浏览器**（Chrome、Edge、Firefox 等）

2. **访问前端地址**
   ```
   http://localhost:5173
   ```

3. **打开浏览器开发者工具**
   - 按 `F12` 键
   - 或右键点击页面 → 选择「检查」

4. **查看控制台日志**
   - 切换到 `Console` 标签
   - 查看是否有错误信息

5. **查看网络请求**
   - 切换到 `Network` 标签
   - 点击「开始排盘」按钮
   - 查看 `/api/fortune/calculate-by-data` 请求
   - 检查状态码是否为 `200 OK`

### 方案 2：运行诊断脚本

如果仍然有问题，运行诊断脚本检查服务状态：

```bash
python kiro/scripts/diagnose_network.py
```

诊断脚本会检查：
- 后端服务是否运行
- 前端服务是否运行
- 后端 API 是否可访问
- 排盘接口是否正常

### 方案 3：重启服务

如果服务未运行或异常，重启服务：

**重启后端服务：**
```bash
# 停止当前服务（Ctrl+C）
cd bazi-admin
python main.py
```

**重启前端服务：**
```bash

```

## 常见问题

### Q1: 为什么不能在微信开发者工具中运行？

**A**: 微信开发者工具主要用于小程序开发，其网络环境与浏览器不同。H5 项目的 Vite 代理配置在微信开发者工具中不生效。

**解决方案**：
- H5 项目：在浏览器中开发和测试
- 小程序项目：在微信开发者工具中开发和测试

### Q2: 为什么需要代理？

**A**: 浏览器的同源策略会阻止跨域请求。

- 前端地址：`http://localhost:5173`
- 后端地址：`http://127.0.0.1:9000`
- 虽然都是本地，但端口不同，浏览器认为是跨域

**Vite 代理的作用**：
- 前端请求 `/api/*` 时
- Vite 自动转发到 `http://127.0.0.1:9000/api/*`
- 浏览器认为是同源请求，不会阻止

### Q3: 生产环境怎么办？

**A**: 生产环境有多种方案：

**方案 1：Nginx 反向代理**
```nginx
location /api {
    proxy_pass http://backend:9000;
}
```

**方案 2：同域部署**
- 前端：`https://example.com`
- 后端：`https://example.com/api`

**方案 3：CORS**
- 后端已配置 CORS（允许所有来源）
- 前端可以直接访问后端

### Q4: 如何在微信开发者工具中测试（不推荐）？

**A**: 如果必须在微信开发者工具中测试：

1. 修改 `my-bazi-app/src/utils/request.ts`：
   ```typescript
   // 临时修改：直接访问后端
   const baseURL = 'http://127.0.0.1:9000'
   ```

2. 在微信开发者工具中：
   - 设置 → 项目设置
   - 勾选「不校验合法域名」

**注意**：这种方式仅用于临时测试，不推荐长期使用。

## 技术细节

### Vite 代理配置

`my-bazi-app/vite.config.ts`：

```typescript
export default defineConfig({
  server: {
    proxy: {
      '/api': {
        target: 'http://127.0.0.1:9000',
        changeOrigin: true,
      }
    }
  }
})
```

### 请求工具配置

`my-bazi-app/src/utils/request.ts`：

```typescript
// 开发环境使用空字符串（通过 Vite 代理）
// 生产环境使用完整 URL
const baseURL = import.meta.env.DEV ? '' : (import.meta.env.VITE_API_BASE_URL || 'http://127.0.0.1:9000')
```

### 后端 CORS 配置

`bazi-admin/main.py`：

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # 允许所有来源
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```
