# 档案管理功能快速启动

## 🚀 快速开始

### 1. 启动后端服务

```bash
# 进入后端目录
cd bazi-admin

# 激活虚拟环境（如果有）
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

# 启动服务
python main.py
```

**验证后端启动成功**:
- 访问 http://127.0.0.1:9000/docs
- 看到 FastAPI 文档页面

### 2. 启动前端服务

```bash
# 进入前端目录
cd my-bazi-app

# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev:h5
```

**验证前端启动成功**:
- 浏览器自动打开 http://localhost:5173
- 看到八字排盘首页

### 3. 快速测试档案功能

#### 方式 1: 从排盘信息页测试

1. 点击底部 TabBar 的"首页"
2. 点击页面上的"开始排盘"按钮（或类似入口）
3. 进入排盘信息页
4. 点击"新建并保存档案"按钮
5. 填写表单并保存

#### 方式 2: 直接访问档案编辑页

在浏览器地址栏输入:
```
http://localhost:5173/#/pages/archive/add
```

### 4. 测试新建档案

填写以下测试数据:
```
姓名: 张三
性别: 男 (乾造)
出生日期: 1990-05-15
出生时间: 14:30
关系标签: 本人
设为默认: ✓
```

点击"保存档案"按钮，等待保存成功。

### 5. 验证档案保存

#### 方式 1: 查看浏览器控制台
```javascript
// 打开浏览器控制台（F12）
// 执行以下代码
const archiveStore = useArchiveStore()
console.log('档案列表:', archiveStore.archives)
console.log('当前档案 ID:', archiveStore.currentArchiveId)
```

#### 方式 2: 查看 localStorage
```javascript
// 打开浏览器控制台（F12）
// 执行以下代码
console.log('本地档案:', localStorage.getItem('bazi_archives'))
console.log('当前档案 ID:', localStorage.getItem('bazi_current_id'))
```

#### 方式 3: 查看数据库
```bash
# 进入后端目录
cd bazi-admin

# 运行检查脚本
python ../kiro/scripts/check_archives.py
```

### 6. 测试编辑档案

1. 返回排盘信息页
2. 在档案列表中找到刚才创建的档案
3. 点击档案卡片（或编辑按钮）
4. 修改部分信息
5. 点击"保存修改"按钮

### 7. 测试删除档案

1. 进入档案编辑页
2. 滚动到页面底部
3. 点击"删除此档案"按钮
4. 在确认对话框中点击"删除"
5. 验证档案是否删除成功

## 🐛 常见问题

### 问题 1: 后端服务启动失败

**错误信息**: `ModuleNotFoundError: No module named 'fastapi'`

**解决方案**:
```bash
cd bazi-admin
pip install -r requirements.txt
```

### 问题 2: 前端服务启动失败

**错误信息**: `Cannot find module 'vite'`

**解决方案**:
```bash
cd my-bazi-app
npm install
```

### 问题 3: 页面显示空白

**可能原因**: 组件导入失败

**解决方案**:
1. 检查浏览器控制台错误信息
2. 检查 `ZenHeader` 组件是否存在
3. 刷新页面重试

### 问题 4: 保存失败

**可能原因**: 后端服务未启动或网络错误

**解决方案**:
1. 检查后端服务是否运行
2. 访问 http://127.0.0.1:9000/docs 验证
3. 检查浏览器控制台网络请求

### 问题 5: TabBar 未隐藏

**可能原因**: `uni.hideTabBar()` 调用失败

**解决方案**:
```javascript
// 在浏览器控制台手动执行
uni.hideTabBar({
  animation: false,
  success: () => console.log('TabBar 已隐藏'),
  fail: (err) => console.error('隐藏失败:', err)
})
```
