#### 2.3 简化版本检测函数

```typescript
// #ifdef H5
async function checkUpdate() {
  try {
    // 加上时间戳防止请求到缓存的 version.json
    const timestamp = new Date().getTime();
    const response = await fetch(`/version.json?t=${timestamp}`);
    const data = await response.json();
    const serverVersion = data.version;
    const localVersion = uni.getStorageSync('APP_VERSION');

    if (localVersion && localVersion !== serverVersion) {
      // 发现新版本，更新本地版本号
      uni.setStorageSync('APP_VERSION', serverVersion);
      
      // 强制重载页面清除缓存
      uni.showModal({
        title: '发现新版本',
        content: '系统已升级，请点击确定刷新页面加载最新内容。',
        showCancel: false,
        success: () => {
          window.location.reload(true); // true 表示硬刷新
        }
      });
    } else if (!localVersion) {
      // 首次访问，记录版本号
      uni.setStorageSync('APP_VERSION', serverVersion);
    }
  } catch (error) {
    console.error('检查版本更新失败:', error);
  }
}
// #endif
```

**主要变化**:
- ✅ 移除了复杂的版本号比较逻辑（`compareVersion` 函数）
- ✅ 使用简单的字符串比较（`!==`）
- ✅ 移除了详细的日志输出
- ✅ 简化了提示框内容
- ✅ 保留了核心功能：检测、提示、刷新

## 功能特点

### 1. 检测时机

✅ **每次页面显示时检测** (`onShow`)

**触发场景**:
- 页面首次加载
- 用户切换标签页回来
- 用户从后台切换回前台
- 页面刷新

**优点**:
- 不会错过任何更新
- 及时通知用户
- 用户体验好

### 2. 防缓存机制

✅ **请求时添加时间戳**

```typescript
const timestamp = new Date().getTime();
const response = await fetch(`/version.json?t=${timestamp}`);
```

**效果**:
- 每次请求 URL 都不同
- 浏览器不会使用缓存
- 始终获取最新版本号

### 3. 强制刷新

✅ **硬刷新机制**

```typescript
window.location.reload(true); // true 表示硬刷新
```

**效果**:
- 强制从服务器重新加载
- 清除所有浏览器缓存
- 确保加载最新资源

### 4. 用户体验

✅ **友好的更新提示**

```typescript
uni.showModal({
  title: '发现新版本',
  content: '系统已升级，请点击确定刷新页面加载最新内容。',
  showCancel: false,  // 无取消按钮，强制更新
  success: () => {
    window.location.reload(true);
  }
});
```

**特点**:
- 提示清晰明确
- 强制更新（无取消按钮）
- 一键刷新

### 5. 首次访问处理

✅ **静默记录版本号**

```typescript
if (!localVersion) {
  // 首次访问，记录版本号
  uni.setStorageSync('APP_VERSION', serverVersion);
}
```

**效果**:
- 首次访问不弹窗
- 建立版本基线
- 下次访问才检测更新

5. 点击确定，页面强制刷新
