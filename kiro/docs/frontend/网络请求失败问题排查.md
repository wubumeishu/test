# 网络请求失败问题排查

## 问题现象

前端在 H5 环境下发起排盘请求时，出现 `request:fail` 错误：

```
❌ [useBaziStore] 排盘失败: {errMsg: "request:fail"}
❌ [useBaziStore] 错误详情: 排盘失败，请检查网络连接
```

## 问题原因

`request:fail` 是 uni-app 的通用网络错误，可能的原因包括：

1. **跨域问题**：浏览器阻止了跨域请求
2. **代理未生效**：Vite 代理配置没有正确工作
3. **后端服务未启动**：后端 API 服务没有运行
4. **环境配置错误**：开发环境配置不正确

## 排查步骤

### 1. 确认后端服务正在运行

```bash
# 检查 9000 端口是否被占用
netstat -ano | findstr :9000

# 应该看到类似输出：
# TCP    127.0.0.1:9000         0.0.0.0:0              LISTENING       23380
```

如果没有输出，说明后端服务未启动，需要启动：

```bash
cd bazi-admin
python main.py
```

### 2. 确认前端开发服务器正在运行

```bash
# 检查 5173 端口是否被占用
netstat -ano | findstr :5173

# 应该看到类似输出：
# TCP    0.0.0.0:5173           0.0.0.0:0              LISTENING       240
```

如果没有输出，说明前端服务未启动，需要启动：

```bash
cd my-bazi-app
npm run dev:h5
```

### 3. 测试后端 API 是否可访问

使用 PowerShell 测试：

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:9000/api/fortune/calculate-by-data" -Method POST -ContentType "application/json" -Body '{"name":"测试","gender":1,"birth_year":2026,"birth_month":4,"birth_day":29,"birth_hour":19,"birth_minute":54}'
```

如果返回 JSON 数据（包含 `success: True`），说明后端 API 正常。

### 4. 检查前端访问方式

**重要**：uni-app H5 项目必须在**浏览器**中访问，不能在微信开发者工具中访问。

正确的访问方式：
- ✅ 在浏览器中打开 `http://localhost:5173`
- ❌ 在微信开发者工具中打开（会导致代理失效）

### 5. 重启前端开发服务器

Vite 代理配置修改后需要重启才能生效：

```bash
# 停止当前服务（Ctrl+C）
# 然后重新启动
cd my-bazi-app
npm run dev:h5
```

## 解决方案

### 方案 1：确保在浏览器中访问（推荐）

1. 停止当前的前端服务（如果在微信开发者工具中运行）
2. 在终端中启动前端服务：
   ```bash
   cd my-bazi-app
   npm run dev:h5
   ```
3. 在**浏览器**中打开 `http://localhost:5173`
4. 打开浏览器控制台（F12），查看网络请求

### 方案 2：检查 Vite 代理配置

确认 `my-bazi-app/vite.config.ts` 中的代理配置正确：

```typescript
export default defineConfig({
  plugins: [uni()],
  server: {
    proxy: {
      '/api': {
        target: 'http://127.0.0.1:9000',
        changeOrigin: true,
        // 不需要 rewrite，因为后端路由就是 /api 开头
      }
    }
  },
  // ...
});
```

### 方案 3：临时绕过代理（仅用于测试）

如果代理始终无法工作，可以临时修改 `my-bazi-app/src/utils/request.ts`：

```typescript
// 临时修改：直接使用后端地址（仅用于开发测试）
const baseURL = 'http://127.0.0.1:9000'
```

**注意**：这种方式会遇到跨域问题，需要在后端添加 CORS 配置。

### 方案 4：后端添加 CORS 支持（如果需要）

如果需要前端直接访问后端（不通过代理），需要在后端添加 CORS 配置。

修改 `bazi-admin/main.py`：

```python
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

# 添加 CORS 中间件
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],  # 允许前端地址
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

## 验证修复

修复后，在浏览器控制台中应该看到：

```
🔄 [useBaziStore] 开始排盘 (通过原始数据)
📤 [useBaziStore] 请求参数: {...}
📥 [useBaziStore] 后端响应: {...}
✅ [useBaziStore] 排盘成功
```

网络面板中应该看到：
- 请求 URL: `http://localhost:5173/api/fortune/calculate-by-data`
- 状态码: `200 OK`
- 响应: JSON 数据

## 常见问题

### Q: 为什么在微信开发者工具中无法访问？

A: 微信开发者工具的网络环境与浏览器不同，Vite 的代理配置在微信开发者工具中不生效。H5 项目应该在浏览器中开发和测试。

### Q: 为什么需要代理？

A: 浏览器的同源策略会阻止前端（`http://localhost:5173`）直接访问后端（`http://127.0.0.1:9000`）。通过 Vite 代理，前端请求 `/api/*` 会被自动转发到后端。

### Q: 生产环境怎么办？

A: 生产环境中，前端会被打包成静态文件，部署到与后端相同的域名下，或者后端配置 CORS 允许跨域访问。
