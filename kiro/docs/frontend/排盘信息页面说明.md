# 排盘信息页面说明

## 📄 文件位置
`my-bazi-app/src/pages/bazi/setup.vue`

## 🎯 页面功能
排盘信息页面是用户进行八字排盘前的信息选择/输入页面，提供两种排盘方式：
1. **选择档案排盘** - 从已保存的档案中选择
2. **快速排盘** - 临时输入信息，不保存档案

## 🎨 UI 设计

### 整体风格
- 极简禅意风格，黑白灰配色
- 宣纸质感背景 (#FCFAF8)
- 朱砂红点缀 (#B22222)
- 大量留白，优雅过渡

### 布局结构

#### 1. 顶部导航
- 使用 `ZenHeader` 组件
- 标题：排盘信息
- 显示返回按钮

#### 2. Tab 切换区
- 两个 Tab：『选择档案』和『快速排盘』
- 底部细线指示当前选中状态
- 平滑过渡动画

#### 3. 选择档案板块
**新建档案入口**
- 虚线边框卡片
- 加号图标 + "新建并保存档案" 文字
- 点击跳转到 `/pages/archive/add`

**档案列表**
- 卡片式布局，每个档案一张卡片
- 显示信息：
  - 姓名（大字，衬线字体）
  - 性别标签（乾造/坤造）
  - 出生日期和时间
  - 关系标签（如"本人"、"伴侣"）
  - 默认标签（右上角朱砂红徽章）
- 点击任意档案触发排盘

**空状态**
- 文件夹图标
- "暂无档案" 提示
- "点击上方按钮创建第一个档案" 引导文字

#### 4. 快速排盘板块
**表单字段**
1. **姓名** - 文本输入框
2. **性别** - 单选按钮组（男/女，乾造/坤造）
3. **出生日期** - 日期选择器（DatePicker）
4. **出生时间** - 时间选择器（TimePicker）

**排盘按钮**
- 全宽黑色按钮
- 文字："开始排盘 (不留档)"
- 点击触发快速排盘

## 🔧 技术实现

### 引入的 Store
```typescript
import { useArchiveStore } from '@/store/useArchiveStore'
import { useBaziStore } from '@/store/useBaziStore'
```

### 状态管理
```typescript
// Tab 状态
const currentTab = ref(0) // 0=选择档案, 1=快速排盘

// 快速排盘表单
const quickForm = reactive({
  name: '',
  gender: 1 as 0 | 1,
  birthDate: '',
  birthTime: ''
})
```

### 核心方法

#### 1. goToCreateArchive()
跳转到新建档案页面
```typescript
uni.navigateTo({
  url: '/pages/archive/add'
})
```

#### 2. selectArchive(archive)
选择档案并排盘
```typescript
// 显示加载提示
uni.showLoading({ title: '正在排盘...', mask: true })

// 调用排盘接口
await baziStore.calculateByArchive(archive.id)

// 跳转到结果页
uni.navigateTo({ url: '/pages/result/result' })
```

#### 3. quickCalculate()
快速排盘（不保存档案）
```typescript
// 表单验证
if (!quickForm.name.trim()) {
  uni.showToast({ title: '请输入姓名', icon: 'none' })
  return
}

// 解析日期和时间
const [year, month, day] = quickForm.birthDate.split('-').map(Number)
const [hour, minute] = quickForm.birthTime.split(':').map(Number)

// 调用排盘接口
await baziStore.calculateByData({
  name: quickForm.name.trim(),
  gender: quickForm.gender,
  birth_year: year,
  birth_month: month,
  birth_day: day,
  birth_hour: hour,
  birth_minute: minute,
  is_deep_analysis: false
})

// 跳转到结果页
uni.navigateTo({ url: '/pages/result/result' })
```

## 📱 交互流程

### 流程 1：选择档案排盘
1. 用户进入页面，默认显示"选择档案" Tab
2. 如果有档案，显示档案列表
3. 用户点击任意档案
4. 显示加载提示："正在排盘..."
5. 调用 `baziStore.calculateByArchive(archiveId)`
6. 排盘成功后跳转到结果页 `/pages/result/result`
7. 如果失败，显示错误提示（Store 中已处理）

### 流程 2：快速排盘
1. 用户切换到"快速排盘" Tab
2. 填写表单：姓名、性别、出生日期、出生时间
3. 点击"开始排盘 (不留档)" 按钮
4. 表单验证（姓名、日期、时间必填）
5. 显示加载提示："正在排盘..."
6. 调用 `baziStore.calculateByData(formData)`
7. 排盘成功后跳转到结果页 `/pages/result/result`
8. 如果失败，显示错误提示（Store 中已处理）

### 流程 3：新建档案
1. 用户点击"新建并保存档案"卡片
2. 跳转到 `/pages/archive/add` 页面
3. 用户填写档案信息并保存
4. 返回后档案列表自动更新（Store 自动持久化）

## 🎯 使用场景

### 场景 1：老用户快速排盘
- 已有多个档案（本人、家人、朋友）
- 直接从列表选择，一键排盘
- 无需重复输入信息

### 场景 2：新用户首次使用
- 点击"新建并保存档案"
- 填写完整信息并保存
- 返回后从列表选择排盘

### 场景 3：临时查询
- 不想保存档案
- 使用"快速排盘"功能
- 输入信息后直接排盘

## 📝 注意事项

1. **表单验证**
   - 快速排盘时必须填写所有字段
   - 姓名不能为空
   - 日期和时间必须选择

2. **加载状态**
   - 排盘时显示 Loading 遮罩
   - 防止用户重复点击
   - 请求完成后自动隐藏

3. **错误处理**
   - Store 中已统一处理错误提示
   - 页面只需 try-catch 捕获即可
   - 失败后停留在当前页面

4. **数据同步**
   - 档案列表自动从 Store 获取
   - Store 会自动加载本地存储
   - 新建档案后自动更新列表

## 📊 数据流向

```
用户操作
  ↓
选择档案 / 填写表单
  ↓
触发排盘方法
  ↓
调用 useBaziStore
  ↓
发送请求到后端 API
  ↓
后端返回排盘结果
  ↓
Store 保存到 currentBaziData
  ↓
跳转到结果页
  ↓
结果页从 Store 读取数据展示
```
