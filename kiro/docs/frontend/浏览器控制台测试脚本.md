# 浏览器控制台测试脚本

## 快速设置测试档案

在浏览器控制台 (F12) 中执行以下代码:

### 方法一: 使用后端已有档案

```javascript
// 1. 设置档案数据 (使用后端已创建的档案ID)
const testArchive = {
  id: '59563ce9-6527-489e-9790-649c2b43e700',  // 后端已创建的档案ID
  name: '测试用户',
  gender: 1,  // 1=男, 0=女
  birthDate: '1990-05-15',
  birthTime: '14:30',
  relation: '本人',
  isDefault: true,
  createdAt: Date.now()
}

// 2. 保存到本地存储
uni.setStorageSync('bazi_archives', [testArchive])
uni.setStorageSync('bazi_current_id', testArchive.id)

// 3. 刷新页面
location.reload()
```

### 方法二: 创建新档案并同步到云端

```javascript
// 1. 生成 UUID
function generateUUID() {
  return 'xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx'.replace(/[xy]/g, function(c) {
    const r = Math.random() * 16 | 0
    const v = c === 'x' ? r : (r & 0x3 | 0x8)
    return v.toString(16)
  })
}

// 2. 创建档案
const newArchiveId = generateUUID()
const newArchive = {
  id: newArchiveId,
  name: '浏览器测试',
  gender: 1,
  birthDate: '1990-05-15',
  birthTime: '14:30',
  relation: '本人',
  isDefault: true,
  createdAt: Date.now()
}

// 3. 保存到本地
uni.setStorageSync('bazi_archives', [newArchive])
uni.setStorageSync('bazi_current_id', newArchiveId)

// 4. 同步到云端
fetch('http://127.0.0.1:9000/api/archives/sync', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    archives: [{
      archive_id: newArchiveId,
      name: newArchive.name,
      gender: newArchive.gender,
      calendar_type: 'solar',
      birth_year: parseInt(newArchive.birthDate.split('-')[0]),
      birth_month: parseInt(newArchive.birthDate.split('-')[1]),
      birth_day: parseInt(newArchive.birthDate.split('-')[2]),
      birth_hour: parseInt(newArchive.birthTime.split(':')[0]),
      birth_minute: parseInt(newArchive.birthTime.split(':')[1]),
      tags: newArchive.relation,
      is_default: newArchive.isDefault,
      local_created_at: newArchive.createdAt
    }]
  })
})
.then(res => res.json())
.then(data => {
  console.log('✅ 同步成功:', data)
  location.reload()
})
.catch(err => console.error('❌ 同步失败:', err))
```

## 故障排查

### 问题 1: 档案不显示

**检查**:
```javascript
console.log('档案:', uni.getStorageSync('bazi_archives'))
console.log('当前ID:', uni.getStorageSync('bazi_current_id'))
```

**解决**: 重新执行设置脚本

### 问题 2: 点击按钮无反应

**检查**:
```javascript
const archiveStore = useArchiveStore()
console.log('Store档案:', archiveStore.archives)
console.log('Store当前ID:', archiveStore.currentArchiveId)
```

**解决**: 刷新页面,确保 Store 已加载

### 问题 3: 报错 "invalid UUID"

**检查**:
```javascript
const id = uni.getStorageSync('bazi_current_id')
console.log('ID:', id)
console.log('长度:', id.length)  // 应该是 36
console.log('格式:', /^[0-9a-f-]{36}$/i.test(id))  // 应该是 true
```

**解决**: 使用标准 UUID 格式的档案ID
