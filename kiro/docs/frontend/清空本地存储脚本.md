# 清空本地存储脚本

## 🎯 问题说明

前端仍在使用旧格式的档案ID（时间戳格式），需要清空本地存储后重新创建档案。

## 📋 错误日志

```
invalid input for query argument $1: '1777374548951' 
(invalid UUID '1777374548951': length must be between 32..36 characters, got 13)
```

## 🛠️ 解决方法

### 方法1：浏览器控制台执行（推荐）

1. 打开浏览器开发者工具（F12）
2. 切换到 Console（控制台）标签
3. 复制粘贴以下代码并回车：

```javascript
// 清空档案数据
uni.removeStorageSync('bazi_archives')
uni.removeStorageSync('bazi_current_id')

// 清空八字历史记录
uni.removeStorageSync('bazi_history')

// 显示提示
console.log('✅ 本地存储已清空')

// 刷新页面
location.reload()
```

### 方法2：应用设置页面

如果应用有设置页面，可以添加"清空数据"按钮：

```vue
<template>
  <view class="settings-page">
    <button @click="clearAllData">清空所有数据</button>
  </view>
</template>

<script setup>
import { useArchiveStore } from '@/store/useArchiveStore'
import { useBaziStore } from '@/store/useBaziStore'

const archiveStore = useArchiveStore()
const baziStore = useBaziStore()

const clearAllData = () => {
  uni.showModal({
    title: '确认清空',
    content: '此操作将清空所有档案和历史记录，是否继续？',
    success: (res) => {
      if (res.confirm) {
        // 清空档案
        archiveStore.clearAllArchives()
        
        // 清空八字历史
        baziStore.clearHistory()
        
        // 清空当前数据
        baziStore.clearCurrentBaziData()
        
        uni.showToast({
          title: '数据已清空',
          icon: 'success',
          duration: 1500
        })
        
        // 延迟刷新
        setTimeout(() => {
          location.reload()
        }, 1500)
      }
    }
  })
}
</script>
```

### 方法3：直接修改 Store（临时方案）

在 `useArchiveStore.ts` 的 `loadFromStorage` 方法中添加自动清理逻辑：

```typescript
const loadFromStorage = async () => {
  try {
    const storedArchives = uni.getStorageSync('bazi_archives')
    
    if (storedArchives && Array.isArray(storedArchives)) {
      // 检查是否有旧格式的ID（纯数字字符串）
      const hasOldFormat = storedArchives.some(archive => /^\d+$/.test(archive.id))
      
      if (hasOldFormat) {
        console.warn('⚠️ 检测到旧格式档案，自动清空...')
        
        // 清空旧数据
        uni.removeStorageSync('bazi_archives')
        uni.removeStorageSync('bazi_current_id')
        
        // 显示提示
        uni.showToast({
          title: '档案格式已更新，请重新创建',
          icon: 'none',
          duration: 3000
        })
        
        archives.value = []
        currentArchiveId.value = ''
        return
      }
      
      archives.value = storedArchives
    }
    
    // ... 其余代码
  } catch (error) {
    console.error('❌ 档案数据加载失败:', error)
  }
}
```

## 🧪 验证步骤

### 1. 清空数据后
```javascript
// 在控制台检查
console.log('档案数据:', uni.getStorageSync('bazi_archives'))
console.log('当前ID:', uni.getStorageSync('bazi_current_id'))
// 应该都返回 null 或 undefined
```

### 2. 创建新档案
```javascript
// 创建档案后检查ID格式
const archiveStore = useArchiveStore()
console.log('新档案ID:', archiveStore.archives[0]?.id)
// 应该是 UUID 格式，如: 'a3f2b8c1-4d5e-4f6a-9b7c-8d9e0f1a2b3c'
```

### 3. 测试排盘
```javascript
// 使用新档案进行排盘
const baziStore = useBaziStore()
await baziStore.calculateByArchive(archiveStore.archives[0].id)
// 应该成功调用后端接口
```

| 档案数量 | 可能有旧档案 | 0 |
| 排盘功能 | ❌ 报错 | ✅ 正常 |

## ⚠️ 注意事项

1. **数据无法恢复** - 清空后旧档案将永久删除
2. **需要重新创建** - 清空后需要重新创建所有档案
3. **历史记录丢失** - 八字排盘历史记录也会被清空

## 🎯 推荐流程

1. ✅ 在控制台执行清空脚本
2. ✅ 刷新页面
3. ✅ 创建新档案（会自动生成UUID格式ID）
4. ✅ 测试排盘功能
5. ✅ 验证后端日志无错误
