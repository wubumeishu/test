# 版本更新操作指南

## 🚀 快速开始

### 每次发版只需 3 步

#### 步骤 1：修改版本号
```bash
# 编辑文件：my-bazi-app/public/version.json
{
  "version": "1.0.1"  # 改大这个数字
}
```

#### 步骤 2：打包
```bash
cd my-bazi-app
npm run build:h5
```

#### 步骤 3：部署
```bash
# 将 dist 目录下的所有文件部署到服务器
# 确保 version.json 也被部署
```

完成！用户下次访问时会自动提示更新。

---

## 📋 版本号规则

### 格式：`主版本号.次版本号.修订号`

#### 修订号 +1（Bug 修复）
```
1.0.0 → 1.0.1
1.0.1 → 1.0.2
1.0.9 → 1.0.10
```

#### 次版本号 +1（新增功能）
```
1.0.9 → 1.1.0
1.1.0 → 1.2.0
1.9.0 → 1.10.0
```

#### 主版本号 +1（重大更新）
```
1.9.9 → 2.0.0
2.0.0 → 3.0.0
```

## 🧪 测试版本更新

### 本地测试

1. **修改版本号**
   ```json
   // public/version.json
   {"version": "1.0.1"}
   ```

2. **清除本地存储**
   - 打开浏览器开发者工具（F12）
   - Application → Local Storage
   - 找到并删除 `APP_VERSION`

3. **刷新页面**
   - 应该看到『发现新版本』提示
   - 点击『立即刷新』
   - 页面重新加载

4. **验证版本号**
   - 打开控制台
   - 查看日志：`📦 [版本检测] 本地版本: 1.0.1`

### 生产测试

1. **部署到测试环境**
2. **清除浏览器缓存**（Ctrl+Shift+Delete）
3. **访问测试环境**
4. **验证更新提示**
5. **确认刷新后加载最新资源**

## ⚠️ 注意事项

### 1. 版本号格式

✅ **正确**：
- `1.0.0`
- `1.0.1`
- `2.0.0`

❌ **错误**：
- `v1.0.0`（不要加 v）
- `1.0`（必须三位）
- `1.0.0.1`（不要超过三位）

### 2. 部署检查

- [ ] `version.json` 文件已部署
- [ ] `version.json` 可以访问（测试：`https://your-domain.com/version.json`）
- [ ] 所有打包文件已部署
- [ ] 文件名包含 hash（如 `index-a1b2c3d4.js`）

### 3. 版本递增

- 每次发版必须递增版本号
- 不要跳过版本号
- 不要降低版本号

## 🐛 常见问题

### Q1：用户没有收到更新提示？

**可能原因**：
1. 版本号没有改变
2. `version.json` 没有部署
3. 用户不是 H5 平台（小程序/App 不支持）

**解决方法**：
1. 确认版本号已修改
2. 确认 `version.json` 可以访问
3. 确认用户使用的是 H5 版本

### Q2：刷新后还是旧版本？

**可能原因**：
1. 浏览器强缓存
2. CDN 缓存
3. 文件名没有 hash

**解决方法**：
1. 清除浏览器缓存（Ctrl+Shift+Delete）
2. 清除 CDN 缓存
3. 检查 Vite 配置

### Q3：频繁提示更新？

**可能原因**：
1. 本地存储被清除
2. 版本号格式错误

**解决方法**：
1. 检查版本号格式
2. 检查浏览器是否禁用了本地存储

## 🚀 自动化建议

### 使用脚本自动更新版本号

创建 `scripts/bump-version.js`：

```javascript
const fs = require('fs');
const path = require('path');

// 读取当前版本
const versionPath = path.join(__dirname, '../public/version.json');
const versionData = JSON.parse(fs.readFileSync(versionPath, 'utf8'));
const currentVersion = versionData.version;

// 解析版本号
const [major, minor, patch] = currentVersion.split('.').map(Number);

// 递增修订号
const newVersion = `${major}.${minor}.${patch + 1}`;

// 写入新版本
versionData.version = newVersion;
fs.writeFileSync(versionPath, JSON.stringify(versionData, null, 2));

console.log(`✅ 版本号已更新：${currentVersion} → ${newVersion}`);
```

使用：
```bash
node scripts/bump-version.js
```
