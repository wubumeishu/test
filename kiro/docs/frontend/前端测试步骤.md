# 前端测试步骤

## 问题说明

前端的档案 ID 必须是标准的 UUID 格式 (36个字符),例如:
```
59563ce9-6527-489e-9790-649c2b43e700
```

而不能是简单的字符串如 `"string"` 或 `"test-001"`。

---

## 解决方案

### 方案一: 在浏览器控制台创建档案

1. 打开前端页面: http://localhost:5173
2. 按 F12 打开开发者工具
3. 在 Console 中执行以下代码:

```javascript
// 生成 UUID
function generateUUID() {
  return 'xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx'.replace(/[xy]/g, function(c) {
    const r = Math.random() * 16 | 0
    const v = c === 'x' ? r : (r & 0x3 | 0x8)
    return v.toString(16)
  })
}

// 创建档案
const archiveStore = useArchiveStore()
const newArchive = {
  id: generateUUID(),  // 生成标准 UUID
  name: '测试用户',
  gender: '男',
  birthDate: '1990-05-15',
  birthTime: '14:30',
  calendarType: 'solar',
  relation: '本人',
  isDefault: true,
  createdAt: Date.now()
}

archiveStore.addArchive(newArchive)
archiveStore.setCurrentArchive(newArchive.id)

console.log('档案创建成功!')
console.log('档案ID:', newArchive.id)
```

4. 然后访问测试页面: http://localhost:5173/#/pages/test/test

### 方案二: 修改 useArchiveStore.ts 的 addArchive 方法

确保在创建档案时使用标准 UUID:

```typescript
// 在 useArchiveStore.ts 中
import { v4 as uuidv4 } from 'uuid'  // 需要安装: npm install uuid

function addArchive(data: Omit<Archive, 'id' | 'createdAt'>) {
  const newArchive: Archive = {
    id: uuidv4(),  // 使用标准 UUID
    ...data,
    createdAt: Date.now()
  }
  
  archives.value.push(newArchive)
  saveToStorage()
}
```

## 完整测试流程

### 1. 在浏览器控制台创建档案

```javascript
// 1. 生成 UUID 函数
function generateUUID() {
  return 'xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx'.replace(/[xy]/g, function(c) {
    const r = Math.random() * 16 | 0
    const v = c === 'x' ? r : (r & 0x3 | 0x8)
    return v.toString(16)
  })
}

// 2. 获取 Store
const { useArchiveStore } = await import('/src/store/useArchiveStore.ts')
const archiveStore = useArchiveStore()

// 3. 创建档案
const archiveId = generateUUID()
console.log('生成的档案ID:', archiveId)

archiveStore.archives.push({
  id: archiveId,
  name: '浏览器测试',
  gender: '男',
  birthDate: '1990-05-15',
  birthTime: '14:30',
  calendarType: 'solar',
  relation: '本人',
  isDefault: true,
  createdAt: Date.now()
})

// 4. 设置为当前档案
archiveStore.currentArchiveId = archiveId

// 5. 保存到本地存储
uni.setStorageSync('bazi_archives', archiveStore.archives)
uni.setStorageSync('bazi_current_id', archiveId)

console.log('✅ 档案创建并设置成功!')
console.log('当前档案:', archiveStore.archives.find(a => a.id === archiveId))
```

## 验证档案 ID 格式

在控制台检查:

```javascript
const archiveStore = useArchiveStore()
const currentId = archiveStore.currentArchiveId

console.log('当前档案ID:', currentId)
console.log('ID长度:', currentId.length)  // 应该是 36
console.log('是否为UUID格式:', /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i.test(currentId))
```

## 常见错误

### 错误 1: "invalid UUID 'string'"

**原因**: 档案ID不是标准UUID格式

**解决**: 使用 `generateUUID()` 生成标准UUID

### 错误 2: "档案不存在"

**原因**: 云端数据库中没有该档案

**解决**: 先调用 `archiveStore.syncWithCloud()` 同步档案

### 错误 3: "未选中档案"

**原因**: `currentArchiveId` 为空

**解决**: 调用 `archiveStore.setCurrentArchive(archiveId)`
