# 测试页面访问指南

## 问题诊断

如果测试页面 `http://localhost:5173/#/pages/test/test` 打不开,可能的原因:

### 1. 路由格式问题

uni-app 的路由格式有两种:

**H5 模式** (浏览器):
```
http://localhost:5173/#/pages/test/test
```

**注意**: 必须有 `#` 号!

### 2. 页面未编译

首次访问新页面时,Vite 会按需编译,可能需要等待几秒。

### 3. 浏览器缓存

清除浏览器缓存后重试:
- Chrome: Ctrl + Shift + Delete
- 或使用无痕模式: Ctrl + Shift + N

---

## 正确的访问方式

### 方式一: 通过首页按钮跳转 (推荐)

1. 访问首页: http://localhost:5173
2. 等待页面加载完成
3. 点击右下角的 **🧪 测试** 浮动按钮
4. 自动跳转到测试页面

### 方式二: 直接访问 URL

在浏览器地址栏输入:
```
http://localhost:5173/#/pages/test/test
```

**注意事项**:
- ✅ 必须包含 `#` 号
- ✅ 路径是 `/pages/test/test` (不是 `/src/pages/test/test`)
- ✅ 确保前端服务正在运行

### 方式三: 通过控制台跳转

在首页按 F12,在控制台执行:
```javascript
uni.navigateTo({
  url: '/pages/test/test'
})
```

## 常见错误及解决方案

### 错误 1: 404 Not Found

**原因**: 路由格式错误或页面未注册

**解决**:
1. 确认 URL 包含 `#` 号
2. 检查 `pages.json` 中是否注册了测试页面
3. 重启前端服务

### 错误 2: 页面空白

**原因**: 页面编译错误或组件加载失败

**解决**:
1. 打开控制台 (F12) 查看错误信息
2. 检查是否有 import 错误
3. 确认所有依赖已安装: `npm install`

### 错误 3: 无限加载

**原因**: 页面编译中或网络请求阻塞

**解决**:
1. 等待 10-20 秒
2. 刷新页面 (F5)
3. 查看终端是否有编译错误

### 错误 4: Cannot read property 'xxx' of undefined

**原因**: Store 未初始化或档案未设置

**解决**:
1. 执行档案设置脚本 (见快速测试指南)
2. 刷新页面
3. 确认 Store 已加载

## 调试技巧

### 1. 查看网络请求

打开控制台 → Network 标签:
- 查看是否有请求发送到 `http://127.0.0.1:9000/api/fortune/calculate`
- 检查请求状态码 (应该是 200)
- 查看响应数据

### 2. 查看控制台日志

打开控制台 → Console 标签:
- 查看是否有错误信息 (红色)
- 查看请求日志 (🚀 开始测试后端排盘...)
- 查看响应日志 (✅ 排盘成功!)

### 3. 查看 Store 状态

在控制台执行:
```javascript
// 导入 Store
const { useArchiveStore } = await import('/src/store/useArchiveStore.ts')
const { useBaziStore } = await import('/src/store/useBaziStore.ts')

const archiveStore = useArchiveStore()
const baziStore = useBaziStore()

// 查看状态
console.log('档案列表:', archiveStore.archives)
console.log('当前档案ID:', archiveStore.currentArchiveId)
console.log('当前档案:', archiveStore.archives.find(a => a.id === archiveStore.currentArchiveId))
console.log('排盘结果:', baziStore.lastResult)
console.log('加载状态:', baziStore.isLoading)
```

### 4. 手动调用 API

在控制台执行:
```javascript
const { useBaziStore } = await import('/src/store/useBaziStore.ts')
const baziStore = useBaziStore()

// 手动调用排盘
baziStore.calculateBazi('59563ce9-6527-489e-9790-649c2b43e700', false)
  .then(result => {
    console.log('✅ 排盘成功:', result)
  })
  .catch(error => {
    console.error('❌ 排盘失败:', error)
  })
```
