# 版本更新快速参考

## 🚀 发布新版本（3 步）

### 1️⃣ 修改版本号

```bash
# 编辑版本文件
vim my-bazi-app/public/version.json
```

```json
{
  "version": "1.0.1"  ← 修改这里
}
```

### 2️⃣ 打包前端

```bash
cd my-bazi-app
npm run build:h5
```

### 3️⃣ 部署到服务器

```bash
# 将 dist/build/h5 目录部署到服务器
# 例如：
scp -r dist/build/h5/* user@server:/var/www/html/
```

✅ **完成！** 用户访问时会自动检测并提示更新。

## 🧪 快速测试（5 步）

### 1️⃣ 清除本地版本号

在浏览器控制台（F12）执行：

```javascript
uni.removeStorageSync('APP_VERSION')
```

### 2️⃣ 刷新页面

按 `F5`，应该**不弹窗**（首次访问）

### 3️⃣ 修改版本号

编辑 `my-bazi-app/public/version.json`：

```json
{
  "version": "1.0.1"
}
```

### 4️⃣ 再次刷新

按 `F5`，应该**弹出更新提示**

### 5️⃣ 确认更新

点击「确定」，页面强制刷新

## 📋 版本号规范

```
主版本号.次版本号.修订号
   ↓       ↓       ↓
  1   .   0   .   1
```

- **主版本号**：重大功能变更（1.0.0 → 2.0.0）
- **次版本号**：新增功能（1.0.0 → 1.1.0）
- **修订号**：问题修复（1.0.0 → 1.0.1）

## 🔍 检查版本号

在浏览器控制台执行：

```javascript
// 查看本地版本号
console.log('本地版本:', uni.getStorageSync('APP_VERSION'))

// 查看服务器版本号
fetch('/version.json?t=' + new Date().getTime())
  .then(res => res.json())
  .then(data => console.log('服务器版本:', data.version))
```

## ⚠️ 常见问题

### 问题：没有弹出更新提示

**解决方法**：

```javascript
// 1. 清除本地版本号
uni.removeStorageSync('APP_VERSION')

// 2. 刷新页面
location.reload()
```

### 问题：修改 version.json 后没生效

**解决方法**：

```bash
# 重启前端开发服务器
# Ctrl+C 停止，然后重新启动
npm run dev:h5
```
