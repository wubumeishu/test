# 结果页面设计说明

## 页面概述

**位置**: `my-bazi-app/src/pages/result/result.vue`

**功能**: 展示八字排盘的完整结果,包括基础信息、四柱八字、日主、五行分析等。

**设计风格**: 极简禅意,黑白灰为主,朱砂红点缀。

---

## 设计理念

### 1. 禅意美学

**色彩**:
- 主色: 黑 (#1A1A1A) - 沉稳、庄重
- 辅色: 灰 (#666, #999) - 中性、平和
- 背景: 米白 (#FBFBFB) - 宣纸质感
- 点缀: 朱砂红 (#C0392B) - 重点突出

**字体**:
- 主字体: Noto Serif SC (思源宋体) - 衬线体,优雅
- 八字字符: 加粗,大字号 - 突出核心信息

**布局**:
- 留白充足 - 呼吸感
- 对称平衡 - 和谐感
- 层次分明 - 秩序感

### 2. 信息层次

```
第一层: 基础信息 (姓名、性别、生日)
   ↓
第二层: 核心八字 (四柱竖排)
   ↓
第三层: 日主与五行 (重点突出)
   ↓
第四层: 五行强度 (数据可视化)
   ↓
第五层: AI 分析 (深度解读)
```

## 页面结构

### 1. 加载状态

**设计**:
- 禅意圆环动画 (双圆旋转)
- 文案: "天机推演中"
- 三点跳动动画

**代码**:
```vue
<view v-if="baziStore.isLoading" class="loading-container">
  <view class="zen-circle">
    <view class="circle-outer"></view>
    <view class="circle-inner"></view>
  </view>
  <text class="loading-text">天机推演中</text>
  <view class="loading-dots">
    <view class="dot"></view>
    <view class="dot"></view>
    <view class="dot"></view>
  </view>
</view>
```

**动画**:
- 外圆: 顺时针旋转 (3秒)
- 内圆: 逆时针旋转 (2秒)
- 圆点: 上下跳动 (1.4秒)

### 2. 基础信息区

**内容**:
- 姓名 (大字号,加粗)
- 性别 (乾造/坤造)
- 公历日期
- 农历日期
- 生肖

**设计特点**:
- 白色卡片
- 细边框 (1rpx)
- 信息对齐
- 分隔线

**代码**:
```vue
<view class="info-section">
  <view class="info-header">
    <text class="name">{{ baziStore.currentBaziData.name }}</text>
    <text class="gender">{{ genderText }}</text>
  </view>
  <view class="date-info">
    <view class="date-row">
      <text class="date-label">公历</text>
      <text class="date-value">{{ baziStore.currentBaziData.solar_date }}</text>
    </view>
    <!-- ... -->
  </view>
</view>
```

### 3. 核心八字区

**布局**: 四柱竖排 (从右到左: 时日月年)

**设计特点**:
- 日柱高亮 (朱砂红)
- 日柱边框 (强调)
- 纳音竖排 (传统)
- 底部横排备用

**四柱结构**:
```
┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐
│ 时  │  │ 日  │  │ 月  │  │ 年  │
│ 癸  │  │ 庚  │  │ 辛  │  │ 庚  │
│ 未  │  │ 辰  │  │ 巳  │  │ 午  │
│路旁土│  │白蜡金│  │白蜡金│  │路旁土│
└─────┘  └─────┘  └─────┘  └─────┘
```

**代码**:
```vue
<view class="bazi-pillars">
  <view class="pillar pillar-day">
    <text class="pillar-label">日</text>
    <view class="pillar-chars">
      <text class="char gan highlight">庚</text>
      <text class="char zhi highlight">辰</text>
    </view>
    <text class="pillar-nayin">白蜡金</text>
  </view>
  <!-- ... -->
</view>
```

### 4. 日主与五行区

**布局**: 左右分栏

**左侧 - 日主**:
- 超大字号 (80rpx)
- 朱砂红色
- 五行属性

**右侧 - 五行统计**:
- 5列网格
- 五行名称
- 个数统计

**代码**:
```vue
<view class="analysis-section">
  <!-- 日主 -->
  <view class="day-master-card">
    <text class="day-master-char">庚</text>
    <text class="day-master-wuxing">金</text>
  </view>
  
  <!-- 五行 -->
  <view class="wuxing-card">
    <view class="wuxing-grid">
      <view class="wuxing-item">
        <text class="wuxing-name">金</text>
        <text class="wuxing-count">3</text>
      </view>
      <!-- ... -->
    </view>
  </view>
</view>
```

### 5. 五行强度区

**设计**: 横向进度条

**特点**:
- 五行名称
- 彩色进度条
- 百分比数值

**颜色映射**:
- 金: #D4AF37 (金色)
- 木: #2D5016 (深绿)
- 水: #1A4D7C (深蓝)
- 火: #C0392B (朱砂红)
- 土: #8B7355 (土黄)

**代码**:
```vue
<view class="strength-item">
  <text class="strength-name">金</text>
  <view class="strength-bar-container">
    <view 
      class="strength-bar" 
      :style="{ width: '38.9%', backgroundColor: '#D4AF37' }"
    ></view>
  </view>
  <text class="strength-value">38.9%</text>
</view>
```

### 6. AI 分析区

**设计**:
- 左侧红色边框
- 浅灰背景
- 预格式化文本

**代码**:
```vue
<view v-if="baziStore.currentBaziData.ai_report" class="ai-section">
  <view class="section-header">
    <text class="section-title">深度解析</text>
  </view>
  <view class="ai-content">
    <text class="ai-text">{{ baziStore.currentBaziData.ai_report }}</text>
  </view>
</view>
```

### 7. 无数据状态

**设计**:
- 居中布局
- 卷轴图标 📜
- 提示文案
- 返回按钮

**代码**:
```vue
<view v-else class="empty-container">
  <view class="empty-content">
    <text class="empty-icon">📜</text>
    <text class="empty-text">暂无排盘数据</text>
    <text class="empty-tip">请先进行八字排盘</text>
    <button class="empty-button" @click="goBack">
      <text class="button-text">返回上页</text>
    </button>
  </view>
</view>
```

## 交互设计

### 1. 返回按钮

**位置**: 左上角  
**样式**: 箭头 + 文字  
**交互**: 点击返回上一页,如果没有上一页则跳转到首页

```typescript
function goBack() {
  uni.navigateBack({
    fail: () => {
      uni.switchTab({
        url: '/pages/index/index'
      })
    }
  })
}
```

### 2. 加载状态

**触发**: `baziStore.isLoading === true`  
**显示**: 禅意圆环 + 文案  
**隐藏**: 数据加载完成后自动切换

### 3. 数据展示

**触发**: `baziStore.currentBaziData !== null`  
**显示**: 完整的排盘结果  
**更新**: 响应式更新

## 数据处理

### 1. 性别转换

```typescript
const genderText = computed(() => {
  if (!baziStore.currentBaziData) return ''
  return baziStore.currentBaziData.gender === 1 ? '乾造' : '坤造'
})
```

### 2. 五行列表

```typescript
const wuxingList = computed(() => {
  if (!baziStore.currentBaziData) return []
  
  const { wuxing_strength, wuxing_summary } = baziStore.currentBaziData
  
  return [
    { 
      name: '金', 
      percent: wuxing_strength.jin, 
      count: wuxing_summary.金 || 0,
      color: '#D4AF37'
    },
    // ...
  ]
})
```
