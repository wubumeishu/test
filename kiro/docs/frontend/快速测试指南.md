## 一键设置测试档案

### 步骤 1: 打开前端页面

在浏览器中访问: **http://localhost:5173**

### 步骤 2: 打开开发者工具

按 **F12** 打开浏览器控制台

### 步骤 3: 执行设置脚本

复制以下**完整代码**,粘贴到控制台,按回车执行:

```javascript
// 一键设置测试档案
(function() {
  console.log('🚀 开始设置测试档案...')
  
  // 使用后端已有的档案
  const testArchive = {
    id: '59563ce9-6527-489e-9790-649c2b43e700',
    name: '测试用户',
    gender: 1,
    birthDate: '1990-05-15',
    birthTime: '14:30',
    relation: '本人',
    isDefault: true,
    createdAt: Date.now()
  }
  
  // 保存到本地存储
  uni.setStorageSync('bazi_archives', [testArchive])
  uni.setStorageSync('bazi_current_id', testArchive.id)
  
  console.log('✅ 档案设置成功!')
  console.log('📋 档案信息:')
  console.log('  - ID:', testArchive.id)
  console.log('  - 姓名:', testArchive.name)
  console.log('  - 生日:', testArchive.birthDate, testArchive.birthTime)
  console.log('')
  console.log('📍 下一步:')
  console.log('  1. 点击首页右下角的 "🧪 测试" 按钮')
  console.log('  2. 或直接访问: http://localhost:5173/#/pages/test/test')
  console.log('  3. 点击 "开始测试后端排盘" 按钮')
  console.log('')
  console.log('⏳ 3秒后自动刷新页面...')
  
  setTimeout(() => {
    location.reload()
  }, 3000)
})()
```

### 步骤 4: 等待页面刷新

脚本执行后会自动刷新页面 (3秒后)

### 步骤 5: 访问测试页面

**方法一**: 点击首页右下角的 **🧪 测试** 浮动按钮

**方法二**: 直接访问 http://localhost:5173/#/pages/test/test

## 故障排查

### 问题 1: 页面打不开

**检查**: 确认前端服务是否运行
```bash
# 在终端查看
http://localhost:5173
```

**解决**: 如果服务未运行,在 `my-bazi-app` 目录执行:
```bash
npm run dev:h5
```

### 问题 2: 档案不显示

**检查**: 在控制台执行
```javascript
console.log('档案:', uni.getStorageSync('bazi_archives'))
console.log('当前ID:', uni.getStorageSync('bazi_current_id'))
```

**解决**: 重新执行步骤3的设置脚本

### 问题 3: 点击按钮无反应

**检查**: 打开控制台查看是否有错误信息

**解决**: 
1. 刷新页面 (F5)
2. 确认后端服务运行正常: http://127.0.0.1:9000/docs
3. 重新执行设置脚本

### 问题 4: 报错 "invalid UUID"

**原因**: 档案ID格式不正确

**解决**: 使用提供的标准UUID格式档案ID:
```
59563ce9-6527-489e-9790-649c2b43e700
```

### 问题 5: 报错 "档案不存在"

**原因**: 后端数据库中没有该档案

**解决**: 使用 curl 测试后端:
```bash
curl -X POST "http://127.0.0.1:9000/api/fortune/calculate" \
  -H "Content-Type: application/json" \
  -d '{"archive_id": "59563ce9-6527-489e-9790-649c2b43e700", "is_deep_analysis": false}'
```

如果返回成功,说明后端正常,前端问题需要检查网络请求。
