## 功能说明

### 1. 当前档案展示

显示从 `useArchiveStore` 中获取的当前选中档案信息:
- 姓名
- 性别
- 生日 (日期 + 时间)
- 历法类型 (公历/农历)
- 档案ID

**如果未选中档案**:
- 显示 "❌ 未选中档案"
- 提示 "请先在首页创建并选择档案"
- 测试按钮禁用

### 2. 测试按钮

**按钮状态**:
- 正常状态: "🚀 开始测试后端排盘"
- 加载状态: "⏳ 正在连接 9000 端口计算中..."
- 禁用状态: 未选中档案或正在加载时

**点击行为**:
1. 检查是否选中档案
2. 调用 `baziStore.calculateBazi(archiveId, false)`
3. 显示加载动画
4. 等待后端响应
5. 展示结果或错误信息

### 3. 加载状态

**显示内容**:
- 旋转的加载动画
- "正在连接后端 API..."
- API 地址: `http://localhost:9000/api/fortune/calculate`

### 4. 结果展示

#### 核心信息卡片
- 八字字符串 (大字体显示)
- 生肖
- 日主 (天干 + 五行)
- 记录ID

#### 四柱详情 (2x2 网格)
每个柱显示:
- 柱名 (年柱/月柱/日柱/时柱)
- 干支 (如: 庚午)
- 纳音 (如: 路旁土)
- 藏干 (如: 丁, 己)

#### 五行强度
每个五行显示:
- 名称 (金/木/水/火/土)
- 进度条 (带颜色)
- 百分比 (如: 38.89%)
- 个数 (如: 3个)

**五行颜色**:
- 金: #FFD700 (金色)
- 木: #228B22 (绿色)
- 水: #1E90FF (蓝色)
- 火: #FF4500 (红色)
- 土: #8B4513 (棕色)

#### 完整 JSON 数据
- 黑色背景的代码块
- 格式化的 JSON 数据
- 可滚动查看
- 包含所有响应字段

### 5. 错误提示

**显示条件**: 请求失败时

**显示内容**:
- ❌ 错误图标
- 错误信息 (如: "排盘失败，请检查后端服务是否启动")

### 6. 使用提示

底部固定显示:
1. 确保后端服务已启动 (端口 9000)
2. 确保已创建并选择档案
3. 点击按钮测试排盘功能
4. 查看返回的八字、五行等数据

## 测试流程

### 完整测试步骤

**1. 启动后端服务**

```bash
cd bazi-admin
uvicorn main:app --host 127.0.0.1 --port 9000 --reload
```

验证: 访问 http://127.0.0.1:9000/docs

**2. 启动前端服务**

```bash
cd my-bazi-app
npm run dev:h5
```

访问: http://localhost:5173

**3. 创建档案**

- 进入首页
- 点击 "添加档案"
- 填写姓名、性别、生日等信息
- 保存档案

**4. 选择档案**

- 在档案列表中选择刚创建的档案
- 确认档案已被选中 (高亮显示)

**5. 进入测试页**

- 跳转到 `/pages/test/test`
- 查看当前档案信息是否正确显示

**6. 执行测试**

- 点击 "开始测试后端排盘" 按钮
- 观察加载状态
- 等待结果返回

**7. 查看结果**

- 核心信息卡片
- 四柱详情
- 五行强度
- 完整 JSON 数据

## 常见问题

### Q1: 显示 "未选中档案"

**原因**: `useArchiveStore` 中没有设置 `currentArchiveId`

**解决**:
1. 进入首页
2. 创建或选择一个档案
3. 确认档案被选中
4. 重新进入测试页

### Q2: 点击按钮无反应

**原因**: 
- 档案未选中
- 正在加载中
- 按钮被禁用

**解决**:
1. 检查档案是否选中
2. 等待上一次请求完成
3. 查看控制台错误信息

### Q3: 显示 "排盘失败"

**原因**:
- 后端服务未启动
- 端口不正确
- 网络连接问题
- 档案ID不存在

**解决**:
1. 检查后端服务是否运行
2. 访问 http://127.0.0.1:9000/docs 验证
3. 查看浏览器控制台网络请求
4. 查看后端控制台日志

### Q4: 数据显示不完整

**原因**: 后端返回数据格式不正确

**解决**:
1. 查看完整 JSON 数据
2. 对比 API 文档
3. 检查后端代码
4. 查看后端日志

### Q5: 五行进度条不显示

**原因**: 
- 数据为 0
- CSS 样式问题

**解决**:
1. 查看 JSON 数据中的 `wuxing_strength`
2. 检查百分比是否正确
3. 查看浏览器开发者工具

## 调试技巧

### 1. 查看控制台日志

**前端控制台**:
```
🚀 开始测试后端排盘...
📤 档案ID: xxx
✅ 排盘成功!
📥 结果: { ... }
```

**后端控制台**:
```
INFO: 127.0.0.1:xxxxx - "POST /api/fortune/calculate HTTP/1.1" 200 OK
```

### 2. 查看网络请求

**浏览器开发者工具 → Network**:
- 找到 `/api/fortune/calculate` 请求
- 查看 Request Payload
- 查看 Response
- 查看状态码

### 3. 使用 Swagger UI

访问 http://127.0.0.1:9000/docs:
1. 找到 `POST /api/fortune/calculate`
2. 点击 "Try it out"
3. 输入档案ID
4. 点击 "Execute"
5. 查看响应

### 4. 查看 Store 状态

在浏览器控制台:
```javascript
// 查看档案 Store
const archiveStore = useArchiveStore()
console.log('当前档案ID:', archiveStore.currentArchiveId)
console.log('档案列表:', archiveStore.archives)

// 查看八字 Store
const baziStore = useBaziStore()
console.log('加载状态:', baziStore.isLoading)
console.log('最近结果:', baziStore.lastResult)
```
