## 数据流转

### 新建档案流程
```
用户填写表单
  ↓
点击保存按钮
  ↓
表单验证
  ↓
调用 addArchive()
  ↓
本地添加档案
  ↓
调用 syncWithCloud()
  ↓
同步到云端
  ↓
设为当前档案
  ↓
返回上一页
```

### 编辑档案流程
```
从档案列表选择档案
  ↓
跳转到编辑页面（带 id 参数）
  ↓
从 Store 中查找档案
  ↓
回显数据到表单
  ↓
用户修改数据
  ↓
点击保存按钮
  ↓
表单验证
  ↓
调用 updateArchive()
  ↓
本地更新档案
  ↓
调用 syncWithCloud()
  ↓
同步到云端
  ↓
设为当前档案
  ↓
返回上一页
```

### 删除档案流程
```
编辑模式下点击删除按钮
  ↓
弹出确认对话框
  ↓
用户确认删除
  ↓
调用 deleteArchive()
  ↓
调用云端删除接口
  ↓
删除本地档案
  ↓
处理当前档案切换
  ↓
调用 fetchArchives() 刷新列表
  ↓
返回上一页
```

## API 接口对应

| 前端方法 | 后端接口 | HTTP 方法 | 说明 |
|---------|---------|----------|------|
| `fetchArchives()` | `/api/archives/list` | GET | 获取档案列表 |
| `addArchive()` | `/api/archives/sync` | POST | 通过同步接口添加 |
| `updateArchive()` | `/api/archives/sync` | POST | 通过同步接口更新 |
| `deleteArchive()` | `/api/archives/{archive_id}` | DELETE | 删除档案 |
| `syncWithCloud()` | `/api/archives/sync` | POST | 云端同步 |

## 关键特性

### 1. 自动设为当前档案
保存档案后，自动将该档案设为 `currentArchiveId`，方便排盘功能直接使用。

```typescript
// 新建模式
const newArchive = await archiveStore.addArchive(formData)
if (newArchive) {
  archiveStore.currentArchiveId = newArchive.id
}

// 编辑模式
await archiveStore.updateArchive(editArchiveId.value, formData)
archiveStore.currentArchiveId = editArchiveId.value
```

### 2. 智能当前档案切换
删除档案时，如果删除的是当前选中的档案，自动切换到其他档案或清空。

```typescript
if (currentArchiveId.value === id) {
  if (archives.value.length > 0) {
    currentArchiveId.value = archives.value[0].id
  } else {
    currentArchiveId.value = ''
  }
}
```

### 3. 本地持久化
使用 watch 监听 archives 和 currentArchiveId 的变化，自动保存到 localStorage。

```typescript
watch(archives, () => {
  saveArchivesToStorage()
}, { deep: true })

watch(currentArchiveId, () => {
  saveCurrentIdToStorage()
})
```

### 4. 云端同步
登录状态下，自动同步本地档案到云端，并获取最新的云端档案列表。

```typescript
// 页面加载时自动同步
if (isLoggedIn.value) {
  await syncWithCloud()
}

// 添加/更新档案后自动同步
if (isLoggedIn.value) {
  await syncWithCloud()
}
```

### 5. 完善的错误处理
所有 CRUD 操作都有完整的 try-catch-finally 错误处理。

```typescript
try {
  isLoading.value = true
  // 执行操作
  uni.showToast({ title: '操作成功', icon: 'success' })
} catch (error) {
  console.error('操作失败:', error)
  uni.showToast({ title: '操作失败', icon: 'error' })
} finally {
  isLoading.value = false
}
```

## 使用示例

### 1. 在排盘信息页使用

```vue
<!-- pages/bazi/setup.vue -->
<template>
  <!-- 新建档案入口 -->
  <view class="create-archive-card" @click="goToCreateArchive">
    <text class="add-icon">add_circle</text>
    <text class="create-text">新建并保存档案</text>
  </view>

  <!-- 档案列表 -->
  <view 
    v-for="archive in archiveStore.archives" 
    :key="archive.id"
    class="archive-item"
    @click="selectArchive(archive)"
  >
    <text class="archive-name">{{ archive.name }}</text>
    <text class="archive-gender">{{ archive.gender === 1 ? '乾造' : '坤造' }}</text>
  </view>
</template>

<script setup>
import { useArchiveStore } from '@/store/useArchiveStore'

const archiveStore = useArchiveStore()

// 跳转到新建档案页
const goToCreateArchive = () => {
  uni.navigateTo({
    url: '/pages/archive/add'
  })
}

// 选择档案并排盘
const selectArchive = async (archive) => {
  await baziStore.calculateByArchive(archive.id)
  uni.navigateTo({
    url: '/pages/result/result'
  })
}
</script>
```
