# UI 设计指南 - 新中式风格

## 设计理念

采用新中式风格，融合传统文化元素与现代简约设计，营造优雅、沉稳、具有文化底蕴的视觉体验。

## 配色方案

### 主色调
- **宣纸米白** `#F9F6F0` - 背景色，营造温润质感
- **纯白** `#FFFFFF` - 卡片背景，提升层次感
- **深墨色** `#333333` - 主文字，沉稳大气
- **朱砂红** `#8B2626` - 主色调/按钮，传统吉祥色

### 辅助色
- **浅灰** `#666666` - 副标题文字
- **占位灰** `#999999` - 占位符文字
- **浅红背景** `#FFF5F5` - 选中状态背景

## 字体规范

### 字号层级
- **大标题** `56rpx` - 页面主标题（如"八字排盘"）
- **副标题** `28rpx` - 页面副标题（如"洞悉先机 · 顺势而为"）
- **按钮文字** `32rpx` - 主要操作按钮
- **表单标签** `30rpx` - 表单项标签
- **输入文字** `28rpx` - 输入框和选择器文字
- **提示文字** `24rpx` - 底部提示文字

### 字重
- **标题** `font-weight: 600` - 加粗，突出重点
- **按钮** `font-weight: 500` - 中等粗细
- **正文** `font-weight: 400` - 常规

### 字间距
- **标题** `letter-spacing: 8rpx` - 大标题舒展
- **副标题** `letter-spacing: 4rpx` - 副标题适中
- **按钮** `letter-spacing: 4rpx` - 按钮文字舒展
- **标签** `letter-spacing: 2rpx` - 标签微调

## 圆角规范

- **卡片** `border-radius: 16rpx` - 大圆角，柔和
- **输入框/选择器** `border-radius: 8rpx` - 小圆角，精致
- **按钮** `border-radius: 48rpx` - 胶囊形，现代感

## 阴影规范

- **卡片阴影** `box-shadow: 0 4rpx 20rpx rgba(0, 0, 0, 0.06)` - 轻柔浮起
- **按钮阴影** `box-shadow: 0 8rpx 24rpx rgba(139, 38, 38, 0.3)` - 朱砂红光晕

## 间距规范

### 外边距
- **页面边距** `padding: 60rpx 40rpx 40rpx` - 上大下小
- **卡片内边距** `padding: 50rpx 40rpx` - 舒适留白
- **表单项间距** `margin-bottom: 40rpx` - 清晰分隔

### 内边距
- **输入框** `padding: 0 24rpx` - 左右留白
- **按钮** 自动居中 - 文字自然呼吸

## 组件设计

### 1. 标题区域
```
标题 (56rpx, 深墨色, 加粗, 8rpx 字间距)
副标题 (28rpx, 浅灰, 4rpx 字间距)
装饰线 (120rpx 宽, 4rpx 高, 渐变)
```

### 2. 表单卡片
```

轻柔阴影
50rpx 上下内边距
40rpx 左右内边距
```

### 3. 输入框
```

8rpx 圆角
88rpx 高度
24rpx 左右内边距
```

### 4. 单选按钮
```
默认: 宣纸米白背景
选中: 浅红背景 + 朱砂红边框
```

### 5. 提交按钮
```

48rpx 圆角（胶囊形）
96rpx 高度
朱砂红光晕阴影

```

## 响应式适配

### 单位使用
- 使用 `rpx` 单位，自动适配不同屏幕
- 1rpx = 屏幕宽度 / 750

### 兼容性
- 使用 `<view>` 替代 `<div>`
- 使用 `<text>` 替代 `<span>`
- 使用 `<input>` 原生组件
- 使用 `<picker>` 原生选择器
- 使用 `<radio-group>` 原生单选组

## 设计原则

1. **留白为美** - 充足的间距营造呼吸感
2. **层次分明** - 通过字号、颜色、阴影区分层级
3. **色彩克制** - 主色调不超过 3 种
4. **细节精致** - 圆角、阴影、字间距精心调校
5. **文化底蕴** - 融入传统元素（乾坤、朱砂红）
6. **现代简约** - 避免过度装饰，保持简洁
