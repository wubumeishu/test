# 档案编辑页面测试指南

## 快速测试步骤

### 1. 启动项目

```bash
# 进入前端项目目录
cd my-bazi-app

# 启动开发服务器
npm run dev:h5
```

### 2. 测试新建档案

#### 步骤 1: 访问新建页面
- 方式 1: 从排盘信息页点击"新建并保存档案"
- 方式 2: 直接访问 `/pages/archive/add`

#### 步骤 2: 填写表单
```
姓名: 张三
性别: 男 (乾造)
出生日期: 1990-05-15
出生时间: 14:30
关系标签: 本人
设为默认: ✓
```

#### 步骤 3: 提交保存
- 点击"保存档案"按钮
- 观察加载状态（按钮显示"保存中..."）
- 等待成功提示

#### 步骤 4: 验证结果
- 页面自动返回上一页
- 在档案列表中查看新建的档案
- 验证该档案是否被设为当前档案

### 3. 测试编辑档案

#### 步骤 1: 选择档案
- 从档案列表中选择一个档案
- 点击编辑按钮（或长按档案卡片）

#### 步骤 2: 验证数据回显
- 检查姓名是否正确显示
- 检查性别是否正确选中
- 检查出生日期是否正确显示
- 检查出生时间是否正确显示
- 检查关系标签是否正确选中
- 检查默认档案状态是否正确

#### 步骤 3: 修改数据
```
修改姓名: 李四
修改关系标签: 朋友
```

#### 步骤 4: 保存修改
- 点击"保存修改"按钮
- 观察加载状态
- 等待成功提示

#### 步骤 5: 验证结果
- 页面自动返回上一页
- 在档案列表中查看修改后的档案
- 验证修改是否生效

### 4. 测试删除档案

#### 步骤 1: 进入编辑模式
- 选择一个档案进入编辑页面

#### 步骤 2: 点击删除按钮
- 滚动到页面底部
- 点击"删除此档案"按钮

#### 步骤 3: 确认删除
- 观察确认对话框是否弹出
- 对话框内容: "确定要删除这个档案吗？删除后无法恢复。"
- 点击"删除"按钮

#### 步骤 4: 验证结果
- 等待删除成功提示
- 页面自动返回上一页
- 在档案列表中验证档案是否已删除

### 6. 测试 UI 交互

#### 测试性别选择

## 常见问题排查

### 问题 1: 页面显示空白
**原因**: 可能是组件导入失败
**解决**: 检查 `ZenHeader` 组件是否正确导入

### 问题 2: 保存失败
**原因**: 后端服务未启动或网络错误
**解决**: 
1. 检查后端服务是否运行
2. 检查网络请求是否正常
3. 查看浏览器控制台错误信息

### 问题 3: 数据未回显
**原因**: 档案 ID 不正确或档案不存在
**解决**: 
1. 检查 URL 参数是否正确
2. 检查档案是否存在于 Store 中
3. 查看控制台日志

### 问题 4: TabBar 未隐藏
**原因**: `uni.hideTabBar()` 调用失败
**解决**: 
1. 检查 `onMounted` 生命周期是否正确执行
2. 查看控制台日志
3. 手动调用 `uni.hideTabBar()`

### 问题 5: 样式显示异常
**原因**: CSS 变量未定义或样式冲突
**解决**: 
1. 检查 CSS 变量是否正确定义
2. 检查是否有全局样式冲突
3. 使用浏览器开发者工具检查元素样式
