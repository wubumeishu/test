# 版本检测功能测试指南

## 快速测试步骤

### 准备工作

确保前端服务正在运行：

```bash
cd my-bazi-app
npm run dev:h5
```

在浏览器中打开：`http://localhost:5173`

### 测试步骤

#### 1. 清除本地版本号（模拟首次访问）

在浏览器控制台（F12 → Console）执行：

```javascript
uni.removeStorageSync('APP_VERSION')
console.log('✅ 已清除本地版本号')
```

#### 2. 刷新页面（首次访问）

- 按 `F5` 刷新页面
- 观察控制台，应该**不会**弹出更新提示
- 执行以下命令查看本地版本号：

```javascript
console.log('本地版本号:', uni.getStorageSync('APP_VERSION'))
// 应该输出: 本地版本号: 1.0.0
```

#### 3. 修改服务器版本号

打开 `my-bazi-app/public/version.json`，修改版本号：

```json
{
  "version": "1.0.1"
}
```

保存文件。

#### 4. 触发版本检测

有两种方式触发检测：

**方式 1：切换标签页**
- 切换到其他浏览器标签页
- 再切换回应用标签页
- 应该弹出「发现新版本」提示框

**方式 2：刷新页面**
- 按 `F5` 刷新页面
- 应该弹出「发现新版本」提示框

#### 5. 确认更新

- 点击提示框中的「确定」按钮
- 页面会强制刷新（硬刷新）
- 刷新后，再次查看本地版本号：

```javascript
console.log('本地版本号:', uni.getStorageSync('APP_VERSION'))
// 应该输出: 本地版本号: 1.0.1
```

#### 6. 验证不再弹窗

- 再次切换标签页或刷新页面
- 应该**不会**再弹出更新提示
- 因为本地版本号已经更新为 `1.0.1`

## 常见问题排查

### 问题 1：没有弹出更新提示

**可能原因**:
1. 版本号没有修改
2. 浏览器缓存了 `version.json`
3. 本地版本号已经是最新

**解决方法**:

```javascript
// 1. 查看本地版本号
console.log('本地版本号:', uni.getStorageSync('APP_VERSION'))

// 2. 查看服务器版本号
fetch('/version.json?t=' + new Date().getTime())
  .then(res => res.json())
  .then(data => console.log('服务器版本号:', data.version))

// 3. 清除本地版本号重新测试
uni.removeStorageSync('APP_VERSION')
console.log('已清除，请刷新页面')
```

### 问题 2：修改 version.json 后没有生效

**可能原因**:
- 开发服务器没有自动重载文件

**解决方法**:

```bash
# 重启前端开发服务器
# 按 Ctrl+C 停止
# 然后重新启动
npm run dev:h5
```

### 问题 3：弹窗后点击确定没有刷新

**可能原因**:
- `window.location.reload(true)` 在某些浏览器中不支持

**解决方法**:

检查浏览器控制台是否有错误信息。如果有问题，可以修改 `App.vue` 中的刷新方式：

```typescript
// 方式 1：使用 location.href
window.location.href = window.location.href

// 方式 2：使用 location.replace
window.location.replace(window.location.href)

// 方式 3：使用 reload (推荐)
window.location.reload(true)
```
