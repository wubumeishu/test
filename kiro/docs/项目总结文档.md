```python
for archive in request.archives:

    if not existing:

        # 请求中的时间戳更晚，执行 UPDATE
```

**本地格式 → 云端格式**:
```typescript
function convertToCloudArchive(local: Archive): CloudArchive {
  return {
    archive_id: local.id,
    name: local.name,
    gender: local.gender === '男' ? 1 : 0,
    calendar_type: local.calendarType,
    birth_year: parseInt(local.birthDate.split('-')[0]),
    birth_month: parseInt(local.birthDate.split('-')[1]),
    birth_day: parseInt(local.birthDate.split('-')[2]),
    birth_hour: parseInt(local.birthTime.split(':')[0]),
    birth_minute: parseInt(local.birthTime.split(':')[1]),
    tags: local.relation,
    is_default: local.isDefault,
    local_created_at: local.createdAt
  }
}
```

**云端格式 → 本地格式**:
```typescript
function convertToLocalArchive(cloud: CloudArchive): Archive {
  return {
    id: cloud.archive_id,
    name: cloud.name,
    gender: cloud.gender === 1 ? '男' : '女',
    birthDate: `${cloud.birth_year}-${pad(cloud.birth_month)}-${pad(cloud.birth_day)}`,
    birthTime: `${pad(cloud.birth_hour)}:${pad(cloud.birth_minute)}`,
    calendarType: cloud.calendar_type,
    relation: cloud.tags || '',
    isDefault: cloud.is_default,
    createdAt: cloud.local_created_at
  }
}
```

#### 自动同步机制

**触发时机**:
1. 应用启动时调用 `loadFromStorage()`
2. 检测到用户已登录 (`isLoggedIn === true`)
3. 自动调用 `syncWithCloud()`

**同步流程**:
```
1. 从本地存储加载数据
   ↓
2. 检查登录状态
   ↓
3. 如果已登录，触发云端同步
   ↓
4. 将本地档案转换为云端格式
   ↓
5. 调用 POST /api/archives/sync
   ↓
6. 接收云端最新数据
   ↓
7. 转换为本地格式并更新 Store
   ↓
8. 自动持久化到本地存储 (watch 机制)
```

**错误处理**:
- 网络失败不影响本地数据
- 显示友好的错误提示
- 自动回滚到本地数据

#### 五行计算算法

**权重分配**:
- 天干: 30%
- 地支: 20%
- 藏干: 10% (平均分配给每个藏干)

**计算公式**:
```
五行强度 = (天干得分 + 地支得分 + 藏干得分) / 总分 × 100%
```

**示例计算**:

八字: 庚午 辛巳 庚辰 癸未

**天干得分**:
- 庚 (金) × 3 = 90分
- 辛 (金) × 1 = 30分
- 癸 (水) × 1 = 30分

**地支得分**:
- 午 (火) × 1 = 20分
- 巳 (火) × 1 = 20分
- 辰 (土) × 1 = 20分
- 未 (土) × 1 = 20分

**藏干得分**:
- 午藏: 丁(火), 己(土) → 各5分
- 巳藏: 丙(火), 戊(土), 庚(金) → 各3.33分
- 辰藏: 戊(土), 乙(木), 癸(水) → 各3.33分
- 未藏: 己(土), 丁(火), 乙(木) → 各3.33分

**总分**: 288分

**五行百分比**:
- 金: 38.89%
- 木: 2.78%
- 水: 13.89%
- 火: 21.53%
- 土: 22.92%

```json
  "total": 5,
  "records": [...]
}
```

**4. GET /api/fortune/records/{record_id}**

功能: 获取单个记录详情

响应: 完整的记录对象

**5. DELETE /api/fortune/records/{record_id}**

功能: 删除测算记录

响应:
```json
{
  "success": true,
  "message": "记录删除成功",
  "record_id": "uuid"
}
```

#### 业务流程

```
1. 接收请求 (档案ID 或 原始数据)
   ↓
2. 查询档案信息 (如果是档案ID)
   ↓
3. 调用 bazi_engine.py 计算八字
   ↓
4. 准备存储数据 (转换为 JSON 格式)
   ↓
5. 存入 records 表 (JSONB 字段)
   ↓
6. 返回精简数据给前端
```

- 合理的错误处理

### 命名规范

**数据库**:
- 表名: 小写复数 (users, archives, records)
- 字段名: 小写下划线 (user_id, created_at)

**Python**:
- 类名: PascalCase (User, Archive, Record)
- 函数名: snake_case (calculate_full_bazi)
- 常量: UPPER_CASE (TIANGAN, DIZHI)

**TypeScript**:
- 接口: PascalCase (Archive, BaziResult)
- 函数: camelCase (addArchive, syncWithCloud)
- 常量: UPPER_CASE (API_BASE_URL)

```
<footer>
```
