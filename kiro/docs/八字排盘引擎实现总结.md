def calculate_full_bazi(

### ✅ 2. 数据结构

**BaziResult** (主结果):
```python
@dataclass
class BaziResult:
    solar_date: str              # 公历日期
    lunar_date: str              # 农历日期
    gender: int                  # 性别
    shengxiao: str               # 生肖
    year_pillar: Pillar          # 年柱
    month_pillar: Pillar         # 月柱
    day_pillar: Pillar           # 日柱
    hour_pillar: Pillar          # 时柱
    bazi_string: str             # 八字字符串
    wuxing_strength: WuxingStrength  # 五行强度
    wuxing_summary: Dict[str, int]   # 五行统计
    day_master: str              # 日主
    day_master_wuxing: str       # 日主五行
```

**Pillar** (四柱):
```python
@dataclass
class Pillar:
    gan: str                     # 天干
    zhi: str                     # 地支
    nayin: str                   # 纳音
    canggan: List[str]           # 藏干
```

**WuxingStrength** (五行强度):
```python
@dataclass
class WuxingStrength:
    jin: float                   # 金 %
    mu: float                    # 木 %
    shui: float                  # 水 %
    huo: float                   # 火 %
    tu: float                    # 土 %
```

### ✅ 3. 五行计算算法

**权重分配**:
- 天干: 30%
- 地支: 20%
- 藏干: 10% (平均分配)

**计算步骤**:
1. 遍历四柱 (年月日时)
2. 统计每个五行的得分
3. 计算总分
4. 转换为百分比

**示例**:
```
八字: 庚午 辛巳 庚辰 癸未

天干得分:
  庚(金) × 3 = 90
  辛(金) × 1 = 30
  癸(水) × 1 = 30

地支得分:
  午(火) × 1 = 20
  巳(火) × 1 = 20
  辰(土) × 1 = 20
  未(土) × 1 = 20

藏干得分:
  午藏: 丁(火), 己(土) → 各5
  巳藏: 丙(火), 戊(土), 庚(金) → 各3.33
  辰藏: 戊(土), 乙(木), 癸(水) → 各3.33
  未藏: 己(土), 丁(火), 乙(木) → 各3.33

结果:
  金: 38.89%
  木: 2.78%
  水: 13.89%
  火: 21.53%
  土: 22.92%
```
