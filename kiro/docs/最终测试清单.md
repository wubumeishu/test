## 🐛 常见问题排查

### 问题 1：十神、长生显示为空

#### 可能原因
1. 后端代码未更新
2. 后端服务未重载
3. 数据绑定错误

#### 排查步骤
1. 检查后端终端，确认服务已重载
2. 打开浏览器 Network 标签，查看响应数据
3. 确认响应中包含 `shishen`、`changsheng`、`canggan_shishen` 字段
4. 检查前端 result.vue 的数据绑定

### 问题 2：藏干十神数量不对

#### 可能原因
1. 后端返回的数组长度不匹配
2. 前端循环逻辑错误

#### 排查步骤
1. 查看响应数据，对比 `canggan` 和 `canggan_shishen` 的长度
2. 确认两者长度相同
3. 检查前端 v-for 循环

### 问题 3：日柱十神不是『日主』

#### 可能原因
1. 前端绑定了后端数据而不是固定值

#### 排查步骤
1. 检查日柱的十神单元格
2. 确认使用的是固定文本『日主』
3. 确认有 `highlight` 类名

### 问题 4：动画不流畅

#### 可能原因
1. 浏览器性能问题
2. CSS 动画冲突

#### 排查步骤
1. 打开浏览器性能监控
2. 检查 CSS 动画定义
3. 尝试减少动画复杂度
