## 一、后端实现

### 1.1 技术栈

- **框架**：FastAPI
- **数据库**：PostgreSQL 15
- **ORM**：SQLAlchemy 2.0
- **八字库**：lunar-python
- **端口**：9000

### 1.2 核心功能

#### 八字计算引擎（`bazi_engine.py`）

**支持的计算**：
- ✅ 四柱八字（年、月、日、时）
- ✅ 天干地支
- ✅ 纳音五行
- ✅ 地支藏干
- ✅ **十神**（比肩、劫财、食神、伤官、偏财、正财、七杀、正官、偏印、正印）
- ✅ **十二长生**（长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养）
- ✅ **藏干十神**（每个藏干对应的十神）
- ✅ 五行强度分析（百分比 + 个数统计）
- ✅ 日主五行判断
- ✅ 生肖判断

**使用 lunar-python 原生方法**：
```python
# 年柱示例
year_pillar = Pillar(
    gan=bazi.getYearGan(),              # 年干
    zhi=bazi.getYearZhi(),              # 年支
    nayin=get_nayin(...),               # 纳音
    canggan=bazi.getYearHideGan(),      # 藏干（数组）
    shishen=bazi.getYearShiShenGan(),   # 年干十神
    changsheng=bazi.getYearDiShi(),     # 年支地势（十二长生）
    canggan_shishen=bazi.getYearShiShenZhi()  # 藏干十神（数组）
)
```

##### users 表
- user_id (UUID, PK)
- username
- created_at, updated_at

- archive_id (UUID, PK)
- user_id (UUID, FK)
- name, gender

## 四、数据流程

### 4.1 排盘流程

```
用户输入
  ↓
前端验证
  ↓
调用 API
  ↓
后端接收
  ↓
查询档案（如果是档案 ID）
  ↓
调用八字引擎
  ↓
计算四柱八字
  ↓
计算十神、长生
  ↓
计算五行强度
  ↓
保存到 records 表
  ↓
返回结果
  ↓
前端展示
```

### 4.2 档案同步流程

```
本地档案
  ↓
调用同步 API
  ↓
POST /api/archives/sync
  ↓
后端接收
  ↓
检查是否存在
  ↓
插入或更新
  ↓
返回成功
  ↓
前端更新状态
```
