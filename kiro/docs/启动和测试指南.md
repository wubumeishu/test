# 八字排盘系统 - 启动和测试指南

## 📋 快速启动

### 1. 后端服务（已启动 ✅）

后端服务已经在运行中：
- **地址**：http://127.0.0.1:9000
- **状态**：运行中
- **数据库**：已连接

如需重启：
```bash
cd bazi-admin
uvicorn main:app --host 127.0.0.1 --port 9000 --reload
```

### 2. 前端服务（需要重启）

**重要**：由于修改了 Vite 配置（添加了代理），需要重启前端服务：

```bash
cd my-bazi-app

# 停止当前服务（Ctrl+C）

# 重新启动
npm run dev:h5
```

启动后访问：http://localhost:5173

1. 点击底部导航栏的『问题』
2. 点击『八字排盘』卡片

#### 方式 A：快速排盘（推荐）

1. 点击『快速排盘』标签

3. 点击『开始排盘（不留档）』

2. 如果没有档案，点击『+ 新建并保存档案』
3. 填写档案信息并保存
4. 返回后选择该档案
5. 点击档案卡片开始排盘

## 🐛 常见问题

### 问题 1：request:fail 错误

**原因**：前端服务没有重启，Vite 代理未生效

**解决**：
```bash
cd my-bazi-app
# Ctrl+C 停止服务
npm run dev:h5
```

### 问题 2：404 Not Found

**原因**：后端服务未启动

**解决**：
```bash
cd bazi-admin
uvicorn main:app --host 127.0.0.1 --port 9000 --reload
```

### 问题 3：数据库连接失败

**原因**：PostgreSQL 未启动

**解决**：
1. 启动 PostgreSQL 服务
2. 确认端口 5433
3. 确认数据库 zen_bazi 存在

### 问题 4：页面显示空白

**原因**：数据结构不匹配

**解决**：
1. 打开浏览器控制台查看错误
2. 检查 API 响应数据结构
3. 检查前端数据绑定

### 问题 5：十神或长生显示为空

**原因**：后端代码未更新

**解决**：
1. 确认后端服务已重载（查看终端日志）
2. 如果没有，手动重启后端服务
