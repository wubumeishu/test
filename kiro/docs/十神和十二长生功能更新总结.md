### 三、API 响应示例

调用排盘接口后，每个柱子（year_pillar, month_pillar, day_pillar, hour_pillar）都会包含以下字段：

```json
{
  "gan": "庚",
  "zhi": "午",
  "nayin": "路旁土",
  "canggan": ["丁", "己"],
  "shishen": "比肩",
  "changsheng": "沐浴",
  "canggan_shishen": ["正官", "正印"]
}
```

### 四、前端使用方法

前端现在可以直接使用这些字段来填充预留的位置：

```vue
<!-- 十神 -->
<view class="shishen-cell">
  <text class="shishen-text">{{ baziStore.currentBaziData.year_pillar.shishen }}</text>
</view>

<!-- 十二长生 -->
<view class="changsheng-cell">
  <text class="changsheng-text">{{ baziStore.currentBaziData.year_pillar.changsheng }}</text>
</view>

<!-- 藏干十神 -->
<view class="sub-shishen-cell">
  <text 
    v-for="(ss, index) in baziStore.currentBaziData.year_pillar.canggan_shishen" 
    :key="index"
    class="sub-shishen-text"
  >
    {{ ss }}
  </text>
</view>
```

5. **藏干十神**：不仅计算天干十神，还计算每个藏干的十神
